# 담당자 피드백 (FEEDBACK)

담당자로부터 받은 피드백을 **원문 그대로** 기록합니다. 요약·의역 금지.

> **상태 값**: `OPEN` (접수) / `IN_REVIEW` (검토 중) / `ACCEPTED` (작업 결정, TASKS.md로 이동) / `REJECTED` (반영 안함) / `DONE` (해결 완료)

---

## 접수 대기 / 진행 중

### FB-001 — ALL 출력 후 시트별 도면 즉시 미리보기
- **수신일**: 2026-04-15
- **경로**: 담당자 전달
- **상태**: ACCEPTED
- **원문**:
  > ALL 버튼을 누르고 각 도면이 저장 된 후 그 시트별로 눌렀을 때 저장된 도면이 2D 뷰 상에 바로바로 나와야 함
- **관련 기능**:
  - [ALL 일괄 출력](../사용자-매뉴얼/4.도면정보 탭/ALL 일괄 출력.md)
  - [시트 선택 시 화면 전환](../사용자-매뉴얼/5.목록 조작/시트 선택 시 화면 전환.md)
- **분해된 작업**: T-004

### FB-002 — 치수 배치를 Osnap 외곽 방향으로
- **수신일**: 2026-04-15
- **경로**: 담당자 전달
- **상태**: ACCEPTED
- **원문**:
  > 치수를 표현할 때 치수에 이용하는 Osnap의 가까운 바깥 쪽으로 치수가 표현 되어야 함
- **관련 기능**:
  - [치수 추출](../사용자-매뉴얼/1.기본-작업/치수 추출.md)
  - [치수 선택 보기](../사용자-매뉴얼/5.목록 조작/치수 선택 보기.md)
  - [치수](../사용자-매뉴얼/2.작업-데이터 탭/치수.md)
- **분해된 작업**: T-005

### FB-003 — 2D 도면 템플릿 그리드 영역 크기 고정
- **수신일**: 2026-04-15
- **경로**: 담당자 전달
- **상태**: ACCEPTED
- **원문**:
  > 템플릿 그리드 각각의 영역의 크기를 정의하고 ISO/X/Y/Z뷰와 우측 BOM테이블, 설계정보 테이블의 크기가 고정되어야 함
- **관련 기능**:
  - [2D 출력](../사용자-매뉴얼/4.도면정보 탭/2D 출력.md)
  - [2D 생성](../사용자-매뉴얼/2.작업-데이터 탭/2D 생성.md)
  - 개발자 문서: [GenerateSheetDrawing2D](../code-reference/form1-drawing-sheets.md#GenerateSheetDrawing2D)
- **분해된 작업**: T-006

### FB-004 — 뷰 내부 모델 최대화 + 라벨·풍선 영역 확보
- **수신일**: 2026-04-15
- **경로**: 담당자 전달
- **상태**: ACCEPTED
- **원문**:
  > ISO/X/Y/Z뷰 내부 모델의 크기를 그리드 내부의 최대 크기로 키워야 함, 하지만 ISO/X/Y/Z 라벨의 영역에 침범하지 않고, 풍선 배치 할 영역을 확보하고 고정해야함
- **관련 기능**:
  - [2D 출력](../사용자-매뉴얼/4.도면정보 탭/2D 출력.md)
  - 개발자 문서: [RenderSheetViewForDrawing](../code-reference/form1-drawing-sheets.md#GenerateSheetDrawing2D) (내부 호출)
- **분해된 작업**: T-007
- **참고**: FB-003과 연관 (같은 2D 도면 레이아웃). T-006 먼저 해결 후 T-007 진행 권장
