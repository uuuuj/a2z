# 담당자 피드백 (FEEDBACK)

담당자로부터 받은 피드백을 **원문 그대로** 기록합니다. 요약·의역 금지.

> **상태 값**: `OPEN` (접수) / `IN_REVIEW` (검토 중) / `ACCEPTED` (작업 결정, TASKS.md로 이동) / `REJECTED` (반영 안함) / `DONE` (해결 완료)

---

## 접수 대기 / 진행 중

_현재 OPEN/IN_REVIEW/ACCEPTED 상태의 피드백이 없습니다._

---

## 완료 (DONE)

_이력 없음_

---

## 거절 (REJECTED)

_이력 없음_

---

## 형식 예시

```
### FB-001 — 풍선이 겹쳐 보임
- **수신일**: 2026-04-14
- **경로**: 담당자 구두 전달
- **상태**: OPEN
- **원문**:
  > ISO 뷰에서 풍선 노트가 부재와 겹쳐서 번호가 안 보입니다.
  > 특히 큰 조립체에서 심해요.
- **관련 기능**: [ISO 뷰](../features/global-views/global-iso.md), [풍선 조정](../features/dimensions/balloon-adjust.md)
- **분해된 작업**: (ACCEPTED 전환 시 기록) T-xxx, T-yyy
```
