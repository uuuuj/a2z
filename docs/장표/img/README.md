# 장표용 이미지

메뉴얼 장표(앱 화면 · 제작도 · 가공도 · 설치도)에 까는 **실제 스크린샷·PDF 캡처**를 여기에 둔다.

| 파일명 | 쓰는 곳 | 내용 |
|---|---|---|
| `앱-화면.png` | 01 앱 화면 | 모델을 연 상태의 프로그램 전체 화면 |
| `제작도.png` | 04 제작도 | 실제로 뽑은 제작도 PDF 1쪽을 이미지로 |
| `가공도.png` | 05 가공도 | 실제로 뽑은 가공도 PDF 1쪽을 이미지로 |
| `설치도.png` | 06 설치도 | 실제로 뽑은 설치도 PDF 1쪽을 이미지로 |

## 규칙

- **가로 1600px 이상** — 슬라이드에서 확대해도 글자가 뭉개지지 않도록.
- 화면 캡처는 **창을 최대화한 상태**로. 잘라내지 말 것 — 마커 좌표가 전체 화면 기준이다.
- 마커(①②③)는 이미지에 굽지 않는다. HTML 쪽에서 `%` 좌표로 얹으므로
  **이미지는 원본 그대로** 두어야 나중에 마커 위치를 고칠 수 있다.
