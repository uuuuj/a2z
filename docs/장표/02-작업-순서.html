2단계
치수 추출
한 번 누르면 아래 다섯 가지가 자동으로 이어진다
›
3단계
시트 선택
도면정보 탭에서 뽑을 도면을 고른다
›
4단계
2D 출력

›
5단계
PDF 출력
파일로 저장. 여러 장이면 일괄 출력
치수 추출 한 번에 벌어지는 일
순서대로 자동 진행
1부재 목록 수집 — 모델에서 부재를 뽑아 번호를 매김
2간섭 검사 — 어느 부재끼리 닿는지 조사
3기준점 수집 — 치수를 걸 형상점 추출
4치수 계산 — 축별 체인 치수 생성
5도면 시트 생성 — 도면을 몇 장 낼지 자동 분할
각 단계는 따로 있는 버튼으로도 실행할 수 있다.
중간에 취소하면 그 단계까지만 반영된다.
자주 헷갈리는 버튼 — 이름이 비슷하지만 다르다
이 버튼이 버튼차이
작업BOM 도면BOM 수집 앞은 부재 전체 목록, 뒤는 고른 시트의 BOM 표
작업2D 생성 도면2D 출력 앞은 전체를 한 장, 뒤는 고른 시트 한 장
작업가공도 출력 도면가공도 일괄 출력 앞은 고른 부재 하나, 뒤는 여러 장 한꺼번에
작업치수 기본치수 추출 앞은 지금 화면 기준 다시 계산, 뒤는 위 다섯 단계 전체
가공도는 이 순서를 타지 않는다 — 부재 목록만 있으면 부재를 고르고 바로 뽑을 수 있다.
🖥️ 화면 세 칸

왼쪽은 작업/데이터 · 부재 정보 · 도면정보 세 탭, 오른쪽은 3D 뷰어. 뷰 전환(ISO·X·Y·Z)과 초기화는 모든 탭에서 쓸 수 있다.

🔁 다시 뽑을 때

부재를 숨기거나 골라 둔 화면 상태가 바뀌면 부재 번호가 달라진다. 같은 번호로 다시 뽑으려면 같은 상태에서 치수 추출부터 다시.

⚠️ 순서를 건너뛰면

부재 목록 없이 2D를 누르면 "BOM 데이터가 없습니다"로 막힌다. 시트 목록은 간섭 검사가 끝나야 만들어진다.
