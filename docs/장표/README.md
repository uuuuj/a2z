# 설명 장표

3D 모델에서 2D 도면이 어떻게 나오는지를 설명하는 **22슬라이드 한 벌**.
앞부분은 메뉴얼(무엇을 눌러 무엇이 나오나), 뒷부분은 룰북(무엇을 가져와 어떤 기준으로 그리나).

| 파일 | 무엇 |
|---|---|
| **[발표.html](발표.html)** | **정본.** 22슬라이드 통합본. CSS·이미지가 전부 안에 있어 이 파일 하나만 옮겨도 열린다 |
| **[발표.pptx](발표.pptx)** | PPT 판. 글자·도형·표가 PowerPoint 개체라 그 자리에서 편집된다 |
| `_발표-pptx빌드.py` | `발표.html` → `발표.pptx` 변환기 |
| `_발표-추출.js` | 위 변환기가 브라우저에 주입하는 측정 스크립트 |
| `img/` | 스크린샷·도면 캡처 원본 (PNG는 `발표.html`에도 박혀 있고, **PDF 5개는 여기에만 있다**) |

> 2026-07-27: 장표를 파일별로 나눠 두던 구조를 접고 `발표.html` 한 개로 합쳤다.
> 통합본에 원본 22장의 글자가 한 자도 빠짐없이 들어간 것을 확인한 뒤 개별 파일 14개를 지웠다.

## 슬라이드 구성

| # | 슬라이드 | |
|---|---|---|
| 1 | 표지 | |
| 2 | 목차 | 항목을 누르면 그 섹션으로 이동 |
| 3 | 프로그램 UI 구성요소 | 앱 화면 위 마커 11개 |
| 4 | 실행 순서 | 같은 화면 위에 누르는 순서 마커 8개 |
| 5 | 작업 순서 | 버튼 다섯 번 + 치수 추출 안에서 벌어지는 일 |
| 6 | 도면 4종 | 각각 무엇이고 몇 장 나오나 |
| 7 | 예시 모델과 부재 분할 | 부재 3개 → 도면 네 종류 |
| 8~11 | 제작도 · 조립도 · 설치도 · 가공도 | 실제 출력 위 마커 |
| 12 | 값의 출처 | BOM 8칸 · 풍선 3종 · 표제부 7칸이 어디서 오나 |
| 13~22 | 룰북 10장 | Osnap 3 · 보조선 2 · 치수 선별 · 각도 · 설치 위치 · BOM 2 |

룰북은 **로직만** 담는다 — 코드 파일·라인 참조는 넣지 않는다.

## 고치는 법

**둘 중 한 곳만 정본으로 쓴다.** 양쪽을 다 고치면 한쪽이 덮인다.

### PPT에서 고칠 때 (권장)

`발표.pptx`를 열어 그대로 편집한다. 편집 가능 범위:

| 대상 | |
|---|---|
| 제목·설명·목록 글자 | ✅ 글상자 469개 |
| 카드·버튼·마커 원·강조 띠 | ✅ 도형 390개 |
| 표 (값의 출처·부재 목록 등) | ✅ PowerPoint 표 4개 |
| 앱 화면·도면 캡처·예시 모델 | ❌ 그림 (원본은 `img/`) |
| 룰북 도해 11개 | ❌ 그림 (SVG라 HTML에서만 고친다) |

이 경우 `_발표-pptx빌드.py`를 **다시 돌리지 않는다** — 돌리면 PPT 편집분이 사라진다.

### HTML에서 고칠 때

`발표.html`을 직접 고친다. 1.6MB지만 본문은 평범한 HTML이고, 큰 덩어리는 `<img src="data:image/png;base64,…">` 뿐이라 글자·수치 수정은 그대로 찾아 고치면 된다.

고친 뒤 PPT도 쓰고 있으면:

```bash
python _발표-pptx빌드.py
```

## 발표할 때

- **→ ← 방향키 · 스페이스 · 화면 클릭**으로 넘긴다 (왼쪽 22% 클릭은 뒤로)
- 목차 항목을 누르면 그 섹션으로 바로 이동
- 오른쪽 아래에 현재 섹션·장 번호, 아래쪽에 진행 막대
- 인쇄(가로)하면 슬라이드 1장 = 종이 1장. 조작 UI는 인쇄에서 빠진다
