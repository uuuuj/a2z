# 설명 장표

**앱을 어떻게 쓰는지**부터 **도면의 각 요소가 왜 그 모습으로 그려지는지**까지를,
사람이 한눈에 보도록 **가로 슬라이드(HTML)** 로 정리해 모아둔 폴더.

진입점은 **[index.html](index.html)** — 여기서 모든 장표가 열린다.

## 두 파트

```
파트 1 · 메뉴얼   "무엇을 눌러 무엇이 나오나"
        ↓ 이렇게 나온 도면의 각 요소가
파트 2 · 룰북     "무엇을 가져와 어떤 기준으로 그리나"
```

- `docs/기술 노트/`는 **텍스트 사양**(정본 기준값) — 정밀하지만 한눈에 안 들어온다.
- 이 폴더는 그 사양을 **발표용 장표**로 시각화 — 빠르게 이해하는 용도.
- 브라우저로 바로 열거나 인쇄(가로)로 PDF를 뽑는다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 표지 겸 전체 목차 — 여기서 시작 |
| `_deck.css` | **공통 스타일** — 색·슬라이드 뼈대·머리말·꼬리말·슬라이드 원형 3종 |
| `_템플릿.html` | 새 룰북 장표 만들 때 복사할 빈 틀 |
| `img/` | 스크린샷·PDF 캡처 |

## 작성 규칙

- **하나의 요소 = 하나의 HTML.** 내용이 많으면 여러 슬라이드로 나누되(세로 스크롤·스냅), **각 슬라이드는 16:9 한 장**으로 한눈에 들어오게.
- 공통 스타일은 반드시 `_deck.css`를 링크한다. **복사해 넣지 말 것** — 색·크기가 장표마다 갈라진다.
- 슬라이드 내부 치수는 `cqh`(슬라이드 높이 %)·`cqw`(폭 %)로만. 창 크기와 무관하게 비율이 유지된다.
- 수치는 **코드 선언부 기준**으로 적는다 — 사양 문서·주석은 옛 값(stale)일 수 있음.
- 슬라이드에 **기준일**을 명기한다(수치는 시점에 따라 바뀜).
- 값의 최종 출처(파일·라인)를 장표 안에 남겨, 나중에 검증 가능하게 한다.
- 제작도 / 가공도처럼 경로가 다르면 **표로 나란히** 비교한다.
