# 시트 선택 시 화면 전환

## 🟢 한 줄로
도면 시트 목록에서 한 시트를 고르면, 그 시트에 속한 부재만 3D 화면에 남기고 확대해 보여줍니다. 시트 종류에 따라 가공도가 자동 실행되거나 설치 치수가 다시 뽑힙니다.

## 📍 위치
- **탭**: 도면정보
- **그룹**: 도면 시트 목록
- **상호작용**: 도면 시트 목록에서 한 시트를 클릭하거나 키보드로 선택을 바꿀 때

## ✅ 작동하려면
- [ ] 도면 생성 버튼으로 도면 시트 목록이 만들어져 있는지

## ▶️ 시트를 고르면 이런 순서로 일어납니다
1. **선택 확인** — 선택이 비어 있으면 아무 일도 하지 않습니다.
2. **화면 갱신 잠시 멈춤** — 여러 단계를 한 번에 반영하려고 업데이트를 중단합니다.
3. **X-Ray 해제** — 반투명 강조 효과를 끄고 강조 목록을 비웁니다.
4. **전체 부재 숨김** — 모델의 모든 부재를 먼저 숨깁니다.
5. **시트 부재만 보이기** — 선택한 시트에 포함된 부재들만 다시 보이게 합니다.
6. **부재 외곽선 유지** — 윤곽선은 기본 초록색으로 유지합니다.
7. **강조 부재 목록 갱신** — 이후 축 전환 버튼이 이 시트 부재를 기준으로 동작하도록 저장합니다.
8. **카메라 이동** — 시트 부재가 한눈에 들어오도록 확대합니다.
9. **풍선·심볼 제거** — 기존 풍선 노트와 간섭 삼각형 심볼을 지웁니다.
10. **화면 갱신 재개** — 잠시 멈췄던 화면을 다시 그립니다.
11. **시트 종류에 따라 갈림** — 아래 "분기 상황" 참고.
12. **BOM 정보 재집계** — 알람 없이 조용히 BOM 정보를 다시 계산해 채웁니다.

## 🔀 분기 상황
### ① 시트 종류
| 상태 | 처리 |
|---|---|
| 가공도 시트 | 해당 부재의 가공도 자동 실행 |
| 그 외(일반·설치도) | 이 시트 부재들의 설치 치수 자동 추출 |

## ⚠️ 에러 메시지와 대처
자동 동작 중 오류가 나면 사용자 화면에는 팝업이 뜨지 않고 조용히 넘어갑니다. 부재가 일부만 보이거나 치수가 제대로 안 잡힌다면 다른 시트를 한 번 선택했다가 다시 원래 시트를 고르세요.

## 🔗 이어지는 작업
- 이 시트의 2D 도면을 뽑으려면 → [2D 출력](../4.도면정보%20탭/2D%20출력.md)
- 이 시트의 PDF를 저장하려면 → [PDF 출력](../4.도면정보%20탭/PDF%20출력.md)
- 전체 시트를 한꺼번에 내보내려면 → [ALL 일괄 출력](../4.도면정보%20탭/ALL%20일괄%20출력.md)
