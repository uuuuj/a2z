# Clash 목록 더블클릭

## 🟢 한 줄로
Clash(간섭) 목록에서 한 행을 더블클릭하면, 서로 부딪히는 두 부재를 같이 골라 화면 가운데로 확대해서 보여줍니다.

## 📍 위치
- **탭**: 작업/데이터
- **그룹**: Clash Detection (Z값 기준 정렬)
- **상호작용**: Clash 목록의 한 행을 마우스로 빠르게 두 번 클릭

## ✅ 하기 전 확인할 것
- [ ] Clash 버튼으로 간섭 검사가 끝나 목록에 결과가 채워져 있는지
- [ ] 더블클릭하려는 행이 선택 가능한 상태인지

## ▶️ 더블클릭하면 이런 순서로 일어납니다
1. **선택 확인** — 더블클릭한 행이 유효한지 점검합니다.
2. **색상 원복** — 이전에 강조되어 있던 부재 색상을 모두 원래 색으로 되돌립니다.
3. **간섭 쌍 동시 선택** — 부딪힌 두 부재를 함께 선택 상태로 만듭니다. 기존 선택은 해제됩니다.
4. **카메라 이동** — 두 부재가 한 화면에 크게 들어오도록 카메라가 자동으로 맞춥니다.

## 🔀 분기 상황
없음 — 항상 같은 순서로 실행됩니다.

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "Clash 표시 중 오류: {메시지}" | 부재 선택/카메라 이동 중 내부 오류 | 다른 행을 더블클릭해 재시도하거나, Clash 버튼으로 다시 간섭 검사를 수행하세요 |
