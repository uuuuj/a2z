# 치수 선택 보기

## 🟢 한 줄로
치수 목록에서 고른 항목들을 3D 화면에 표시합니다. 같은 축 방향 치수끼리는 자동으로 간격을 벌려 겹치지 않게 그립니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: 체인 치수 목록
- **라벨**: [선택 보기]

## ✅ 누르기 전 확인할 것
- [ ] 치수 추출(치수 버튼)이 끝나 치수 목록에 항목이 있는지
- [ ] 치수 목록에서 1개 이상 선택했는지

## ▶️ 누르면 이런 순서로 일어납니다
1. **선택 확인** — 선택이 비어 있으면 "치수를 선택해주세요." 팝업 후 종료.
2. **화면 갱신 잠시 멈춤** — 여러 치수를 한 번에 추가하기 위해 업데이트를 중단합니다.
3. **기존 간섭 심볼 제거** — 화면에 떠 있던 삼각형 심볼을 지웁니다. 이미 표시된 치수는 그대로 둡니다.
4. **치수 스타일 설정** — 단위·접두사 없이 소수점 없는 정수로 표시하고, 파란색·굵은 글씨(14pt)로 설정합니다.
5. **축별 간격 카운터 초기화** — X/Y/Z 방향별로 간격 누적값(50mm 단위)을 0으로 맞춥니다.
6. **선택한 치수를 하나씩 그리기** — 각 치수의 축 방향에 따라 간격을 누적해 오프셋을 주면서, 같은 방향 치수끼리 겹치지 않게 그립니다.
7. **피벗 지점 설정** — 첫 번째 치수 중심으로 회전·확대의 기준점을 맞춥니다.
8. **화면 갱신 재개** — 치수가 한 번에 나타납니다.
9. **완료 알림** — "{N}개의 치수가 표시되었습니다." 팝업.

## 🔀 분기 상황
### ① 축 방향별 간격 방향
| 치수 축 | 간격을 적용하는 방향 |
|---|---|
| X축 치수 | Y 방향으로 오프셋 |
| Y축 치수 | X 방향으로 오프셋 |
| Z축 치수 | X 방향으로 오프셋 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "치수를 선택해주세요." | 치수 목록에서 아무것도 고르지 않음 | 목록에서 1개 이상 선택 후 다시 누르세요 |
| "치수 표시 중 오류: {메시지}" | 치수 추가 과정에서 내부 오류 | 일부 치수만 표시된 경우 다시 눌러 재시도하세요 |
