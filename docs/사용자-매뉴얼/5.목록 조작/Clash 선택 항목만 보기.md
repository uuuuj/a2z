# Clash 선택 항목만 보기

## 🟢 한 줄로
Clash 목록에서 고른 행들의 부재만 X-Ray 모드로 강조하고, 간섭 지점에 노란 삼각형 심볼을 띄운 뒤 그 부재들 기준으로 특징점과 치수를 자동으로 다시 뽑아줍니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: Clash Detection (Z값 기준 정렬)
- **라벨**: [선택 항목만 보기]

## ✅ 누르기 전 확인할 것
- [ ] Clash 목록에 간섭 결과가 채워져 있는지
- [ ] Clash 목록에서 보고 싶은 행을 1개 이상 선택했는지
- [ ] BOM 목록이 수집되어 있는지 (부재 범위 계산에 사용)

## ▶️ 누르면 이런 순서로 일어납니다
1. **선택 확인** — Clash 목록 선택이 비어 있으면 "Clash 항목을 선택해주세요." 팝업 후 종료.
2. **화면 갱신 잠시 멈춤** — 아래 작업을 한 번에 모아 처리하기 위해 화면 업데이트를 잠시 중단합니다.
3. **X-Ray 모드 켜기** — 선택하지 않은 부재는 반투명해지고, 선택 부재는 선명히 강조됩니다.
4. **이전 X-Ray 선택 해제** — 직전에 강조되어 있던 대상이 있으면 먼저 풉니다.
5. **선택된 간섭 쌍의 부재 수집** — 고른 행마다 두 부재를 모아 목록으로 만듭니다.
6. **X-Ray로 부재 강조** — 수집한 부재들만 X-Ray에 등록해 강조 표시합니다.
7. **카메라 이동** — 강조된 부재가 한눈에 들어오도록 확대합니다.
8. **간섭 지점 심볼 표시** — 두 부재가 겹치는 영역 중심에 노란 삼각형(5mm)을 표시합니다.
9. **화면 갱신 재개** — 잠시 멈췄던 화면을 다시 그립니다.
10. **특징점 자동 재수집** — 강조된 부재들만을 기준으로 특징점을 다시 뽑아 목록에 채웁니다.
11. **치수 자동 재추출** — 같은 부재 범위로 치수 목록도 다시 만듭니다.

## 🔀 분기 상황
### ① 간섭 쌍에서 부재 매칭이 안 되면?
| 상태 | 처리 |
|---|---|
| 두 부재 모두 BOM에서 찾힘 | 해당 행의 삼각형 심볼 표시 + 범위 포함 |
| 한쪽이라도 못 찾음 | 그 행의 삼각형 심볼은 건너뜀 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "Clash 항목을 선택해주세요." | 목록에서 선택이 없음 | 먼저 한 행 이상 클릭해 선택하세요 |
| "Clash 표시 중 오류: {메시지}" | 강조/심볼 표시 중 내부 오류 | 전체 보기로 복귀 후 재시도하세요 |

## 🔗 이어지는 작업
