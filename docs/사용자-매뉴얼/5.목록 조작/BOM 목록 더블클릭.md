# BOM 목록 더블클릭

## 🟢 한 줄로
BOM 목록에서 부재 한 줄을 더블클릭하면, 3D 화면에서 그 부재만 골라 선택하고 카메라가 그 부재로 확대해 들어갑니다.

## 📍 위치
- **탭**: 작업/데이터
- **그룹**: BOM 데이터
- **상호작용**: BOM 목록의 한 행을 마우스로 빠르게 두 번 클릭

## ✅ 하기 전 확인할 것
- [ ] BOM 버튼으로 부재 목록이 수집되어 있는지
- [ ] BOM 목록에서 보고 싶은 행을 한 번 클릭해 선택 상태로 만들었는지

## ▶️ 더블클릭하면 이런 순서로 일어납니다
1. **선택 확인** — 더블클릭한 행이 유효한지 점검합니다. 선택이 없거나 인식 못 하면 아무 일도 일어나지 않습니다.
2. **부재 단독 선택** — 3D 화면에 남아 있던 기존 선택은 모두 풀리고, 더블클릭한 부재 하나만 선택 상태가 됩니다.
3. **카메라 이동** — 해당 부재가 화면 가운데에 크게 보이도록 카메라가 자동으로 날아가 맞춥니다.

## 🔀 분기 상황
없음 — 항상 같은 순서로 실행됩니다.

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "노드 이동 중 오류: {메시지}" | 부재를 선택하거나 카메라를 이동시키는 과정에서 내부 오류가 발생 | 모델을 다시 열거나, 다른 행을 더블클릭해 재시도하세요 |

## 🔗 이어지는 작업
- 선택된 부재의 속성을 보고 싶으면 → [3D 뷰어에서 부재 클릭](../3.부재 정보 탭/3D 뷰어에서 부재 클릭.md) (더블클릭으로도 자동 실행)
- 이 부재의 가공도를 뽑고 싶으면 → [가공도 출력](../2.작업-데이터 탭/가공도 출력.md)
