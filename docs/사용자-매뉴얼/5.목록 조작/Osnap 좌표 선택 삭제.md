# Osnap 좌표 선택 삭제

## 🟢 한 줄로
특징점 목록에서 고른 좌표를 지우고, 남은 좌표의 번호를 1부터 다시 매깁니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: Osnap 좌표 목록
- **라벨**: [선택 삭제]

## ✅ 누르기 전 확인할 것
- [ ] 특징점 목록에서 지울 좌표를 1개 이상 선택했는지

## ▶️ 누르면 이런 순서로 일어납니다
1. **선택 확인** — 선택이 비어 있으면 "삭제할 Osnap 좌표를 선택해주세요." 팝업 후 종료.
2. **삭제 순서 정리** — 뒤쪽 행부터 지우도록 역순 정렬해 번호 밀림을 막습니다.
3. **데이터·부재명·목록 제거** — 해당 행을 저장소 세 곳(좌표, 부재명 포함 좌표, 목록 화면)에서 같이 지웁니다.
4. **번호 재정렬** — 남은 항목을 #1부터 다시 번호 매김.
5. **완료 알림** — 삭제 개수를 팝업으로 보여줍니다.

## 🔀 분기 상황
없음 — 항상 같은 순서로 실행됩니다.

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "삭제할 Osnap 좌표를 선택해주세요." | 목록에서 아무것도 고르지 않음 | 목록에서 1개 이상 선택 후 다시 누르세요 |
| "Osnap 삭제 중 오류: {메시지}" | 삭제 중 내부 오류 | 일부만 지워졌을 수 있으니 재시도하세요 |
