# Clash 전체 보기

## 🟢 한 줄로
X-Ray 강조·가공도 모드·색상 변경·간섭 심볼 등 모든 강조 상태를 초기화하고, 전체 부재가 다 보이는 처음 화면으로 되돌립니다. 치수도 모두 다시 표시합니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: Clash Detection (Z값 기준 정렬)
- **라벨**: [전체 보기]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지

## ▶️ 누르면 이런 순서로 일어납니다
1. **화면 갱신 잠시 멈춤** — 여러 작업을 한 번에 반영하기 위해 업데이트를 중단합니다.
2. **숨겨둔 부재 전부 되살리기** — "선택 항목만 보기"로 숨겨졌던 부재를 모두 다시 보이게 합니다.
3. **X-Ray 모드 끄기** — 반투명 강조 효과가 해제됩니다.
4. **강조 부재 목록 비우기** — 내부에 저장된 강조 대상 목록을 모두 비웁니다.
5. **부재 색상 원복** — 변경되었던 모든 색상을 원래대로 되돌립니다.
6. **간섭 삼각형 심볼 제거** — 노란 삼각형 표시를 모두 지웁니다.
7. **부재 외곽선 복원** — 윤곽선을 기본 초록색으로 되돌립니다.
8. **전체 화면 맞춤** — 모델 전체가 보이도록 카메라를 맞춥니다.
9. **화면 갱신 재개** — 잠시 멈췄던 화면을 다시 그립니다.
10. **모든 치수 다시 표시** — 필터되어 숨겨진 치수까지 모두 3D에 다시 띄웁니다.

## 🔀 분기 상황
없음 — 항상 같은 순서로 실행됩니다.
