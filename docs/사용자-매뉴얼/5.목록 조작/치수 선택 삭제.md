# 치수 선택 삭제

## 🟢 한 줄로
치수 목록에서 고른 항목을 데이터와 화면 양쪽에서 지우고, 남은 치수의 번호를 다시 매긴 뒤 3D에 남은 치수를 다시 그립니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: 체인 치수 목록
- **라벨**: [선택 삭제]

## ✅ 누르기 전 확인할 것
- [ ] 치수 목록에서 지울 치수를 1개 이상 선택했는지

## ▶️ 누르면 이런 순서로 일어납니다
1. **선택 확인** — 선택이 비어 있으면 "삭제할 치수를 선택해주세요." 팝업 후 종료.
2. **삭제 순서 정리** — 고른 행 번호를 뒤에서부터 지우도록 역순으로 정렬해 번호 꼬임을 막습니다.
3. **데이터와 목록 동시 제거** — 선택된 치수를 데이터 저장소와 목록 화면에서 같이 지웁니다.
4. **번호 재정렬** — 남은 치수의 No. 값과 목록 첫 열을 1부터 다시 매깁니다.
5. **3D 치수 다시 그리기** — 기존에 표시되던 3D 치수를 모두 지운 뒤, 남은 치수 전체를 다시 화면에 반영합니다.
6. **완료 알림** — 삭제 개수와 남은 개수를 팝업으로 보여줍니다.

## 🔀 분기 상황
없음 — 항상 같은 순서로 실행됩니다.

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "삭제할 치수를 선택해주세요." | 치수 목록에서 아무것도 고르지 않음 | 목록에서 1개 이상 선택 후 다시 누르세요 |
| "치수 삭제 중 오류: {메시지}" | 삭제/재표시 과정에서 내부 오류 | 일부만 지워졌을 수 있으니 다시 시도하세요 |
