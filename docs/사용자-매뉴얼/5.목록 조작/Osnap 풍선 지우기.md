# Osnap 풍선 지우기

## 🟢 한 줄로
3D 화면에 떠 있는 특징점 풍선 노트와 빨간 구 마커를 한 번에 모두 지웁니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: Osnap 좌표 목록
- **라벨**: [풍선 지우기]

## ✅ 누르기 전 확인할 것
없음. 풍선이나 구 마커가 없는 상태에서 눌러도 안전합니다.

## ▶️ 누르면 이런 순서로 일어납니다
1. **풍선 노트 제거** — 화면에 떠 있는 모든 풍선 텍스트가 사라집니다.
2. **구 마커 제거** — 빨간 구 마커도 한꺼번에 지워집니다.

## 🔀 분기 상황
없음 — 항상 같은 순서로 실행됩니다.

## ⚠️ 에러 메시지와 대처
이 버튼은 오류가 나도 사용자 화면에 팝업 없이 조용히 끝납니다. 풍선/마커가 화면에 남아 있다면 버튼을 한 번 더 눌러보세요.
