# Clash 선택 시 자동 필터

## 🟢 한 줄로
Clash 목록에서 어떤 행을 고르면, 그 간섭에 관련된 부재를 기준으로 특징점 목록과 치수 목록에서 관련 항목을 자동으로 같이 선택해 줍니다.

## 📍 위치
- **탭**: 작업/데이터
- **그룹**: Clash Detection (Z값 기준 정렬)
- **상호작용**: Clash 목록에서 한 행을 클릭하거나 키보드로 선택을 바꿀 때

## ✅ 작동하려면
- [ ] Clash 목록과 BOM 목록에 데이터가 있는지
- [ ] 특징점 목록과 치수 목록이 화면에 보이는 상태인지

## ▶️ 선택을 바꾸면 이런 순서로 일어납니다
1. **선택 확인** — 목록 선택이 비어 있으면 아무 일도 하지 않습니다.
2. **관련 부재 이름 모으기** — 고른 행들의 "부재 1/부재 2" 이름을 모아 중복 없이 집계합니다.
3. **관련 부재 범위 계산** — BOM에서 두 부재를 찾아 둘러싸는 박스 범위(최소/최대 좌표)를 하나로 합칩니다.
4. **특징점 목록 자동 선택** — 관련 부재에서 뽑힌 특징점들이 자동으로 선택 상태가 됩니다. 부재 이름이 맞거나, 좌표가 박스 안(1mm 여유)에 들어오면 선택됩니다.
5. **치수 목록 자동 선택** — 같은 규칙으로 관련 치수들이 자동 선택됩니다.
6. **스크롤 맞춤** — 자동 선택된 첫 항목이 목록에 보이도록 스크롤을 움직입니다.

## 🔀 분기 상황
### ① 간섭 쌍에서 부재 매칭 결과에 따라
| 상태 | 처리 |
|---|---|
| 두 부재 모두 BOM에서 찾힘 | 박스 범위를 결합해 넓은 영역으로 비교 |
| 한쪽이라도 못 찾음 | 그 행은 이름만 비교 대상에 남김 |

## ⚠️ 에러 메시지와 대처
자동 동작 중 오류가 나면 조용히 무시되고 화면에는 팝업이 뜨지 않습니다. 자동 선택이 반영되지 않는 경우가 있을 수 있습니다. 필요하면 Clash 선택을 풀고 다시 고르거나, 목록에서 수동으로 선택하세요.

## 🔗 이어지는 작업
- 자동 선택된 치수를 3D에 표시하려면 → [치수 선택 보기](./치수 선택 보기.md)
- 자동 선택된 특징점에 풍선을 달려면 → [Osnap 선택 좌표 보기](./Osnap 선택 좌표 보기.md)
- 간섭 쌍을 X-Ray로 강조하려면 → [Clash 선택 항목만 보기](./Clash 선택 항목만 보기.md)
