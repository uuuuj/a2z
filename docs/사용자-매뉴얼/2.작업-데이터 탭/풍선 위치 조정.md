# 풍선 위치 조정

## 🟢 한 줄로
ISO/축 뷰에서 자동 배치된 **번호 풍선이 겹치거나 가려질 때**, 사용자가 직접 풍선을 옮길 수 있는 창을 엽니다. 조정값은 저장돼 다음번에도 반영됩니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: BOM 데이터
- **라벨**: [풍선 위치 조정]

## ✅ 누르기 전 확인할 것
- [ ] BOM 목록에 부재가 있는지 ([BOM](./BOM.md) 먼저)
- [ ] 글로벌 뷰(ISO/X축/Y축/Z축) 버튼을 이미 눌러서 **풍선이 화면에 표시된 상태**인지

## ▶️ 누르면 이런 순서로 일어납니다
1. **BOM 비었는지 확인** — 비어 있으면 [에러 ①]
2. **풍선 뷰 활성화 상태 확인** — 뷰 버튼을 먼저 안 눌렀다면 [에러 ②]
3. **선택 부재 파악** — [분기 ①]
4. **위치 조정 다이얼로그 표시** — 어떤 부재의 풍선을 얼마만큼 이동할지 입력
5. **[확인] 누르면 조정값 저장** — 부재 번호와 이동 오프셋을 내부 저장
6. **현재 뷰에 맞춰 풍선 다시 그리기** — 조정한 위치로 풍선 재배치

## 🔀 분기 상황
### ① 다이얼로그의 기본 선택 부재
| 상태 | 기본 선택 |
|---|---|
| BOM 목록에서 부재를 선택해 둠 | 그 부재가 기본 선택됨 |
| 선택 없음 | BOM 목록의 첫 번째 부재가 기본 선택 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "BOM 데이터가 없습니다..." | BOM 목록이 비어 있음 | [BOM] 버튼으로 먼저 부재 목록을 수집하세요 |
| "먼저 뷰(ISO/X/Y/Z) 버튼을 클릭하여 풍선을 표시하세요." | 풍선을 표시하는 뷰 버튼을 아직 안 누름 | [글로벌 ISO](./글로벌%20ISO.md) 또는 축 뷰를 먼저 눌러 풍선이 보이게 한 뒤 다시 시도 |
