# 2D 생성

## 🟢 한 줄로
BOM에 모아둔 **모든 부재를 한 장의 2D 도면**으로 뽑습니다. 은선(점선), 번호 풍선, 보조선까지 자동 배치됩니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: 작업
- **라벨**: [2D 생성]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지
- [ ] BOM 목록에 부재가 1개 이상 있는지 ([BOM](./BOM.md) 수집 필요)

## ▶️ 누르면 이런 순서로 일어납니다
1. **모델 열림 여부 확인** — 안 열려 있으면 [에러 ①]
2. **BOM 점검** — 수집된 부재가 0개면 [에러 ②]
3. **도면 제목(기준 이름) 결정** — [분기 ①]
4. **내부 임시 시트 생성** — 모든 BOM 부재를 한 장에 묶음
5. **2D 도면 그리기 시작** — 화면이 3D+2D 분할 모드로 바뀜
6. **은선(가려진 모서리) 점선 처리** — CAD 스타일로 숨은 선 표현
7. **부재마다 번호 풍선 배치** — 겹치면 자동으로 위치 조정
8. **보조선·치수 추가** — 가독성 향상
9. **완료** — 화면 오른쪽에 2D 도면 영역이 등장

## 🔀 분기 상황
### ① 도면 제목은 어떻게 정해지나요?
| 상태 | 제목으로 들어가는 값 |
|---|---|
| 트리에서 노드를 선택해 둠 | 그 노드 이름 (없으면 파일명) |
| 선택 안 했고 파일 경로가 있음 | 파일명 (확장자 제외) |
| 선택 안 했고 파일 경로도 없음 | "전체" |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "먼저 모델을 열어주세요." | 3D 모델 미로드 | [파일 열기]로 `.vizx`·`.viz` 파일을 먼저 여세요 |
| "BOM 데이터가 없습니다. 먼저 BOM을 수집해주세요." | BOM 수집을 건너뜀 | [BOM] 버튼을 먼저 눌러 수집하세요 |
