# Osnap

## 🟢 한 줄로
부재마다 **특징점(꼭짓점·선의 시작점/끝점·원의 중심점 등)**을 자동으로 수집하고, 곧바로 치수까지 뽑습니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: 작업
- **라벨**: [Osnap]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지
- [ ] 특징점을 모으고 싶은 부재가 화면에 보이는지
- [ ] 특정 부재만 대상으로 하려면 미리 선택(X-Ray 선택)

## ▶️ 누르면 이런 순서로 일어납니다
1. **이전 특징점 목록 비우기** — 좌표 목록과 이름 포함 목록 모두 초기화
2. **간섭 검사에서 생긴 삼각형 심볼 제거** — 화면 정리
3. **부재 노드 전체 획득**
4. **대상 부재 범위 결정** — [분기 ①]
5. **부재마다 특징점 조회** — 선의 시작/끝점, 점의 중심점
6. **종류별 처리** — [분기 ②]
7. **특징점 목록 갱신** — 번호/부재명/X/Y/Z/홀 크기/장공 크기 표시
8. **홀 크기 매칭** — 해당 좌표가 실제 홀 위치에 있으면 크기 정보 연결
9. **요약 팝업** — 선(LINE)·원(CIRCLE)·점(POINT)·면(SURFACE) 각 개수 표시
10. **자동 치수 추출** — 특징점이 1개 이상이면 곧바로 치수까지 생성

## 🔀 분기 상황
### ① 어떤 부재의 특징점을 수집하나요?
| 상태 | 대상 |
|---|---|
| X-Ray로 선택한 부재가 있음 | 선택한 부재만 (필터 모드) |
| 선택 없음 | 화면에 보이는 부재만 |
| 필터 결과 0개 | 전체 부재 (fallback) |

### ② 특징점 종류별 처리
| 종류 | 처리 |
|---|---|
| 선(LINE) | 시작점·끝점 모두 수집 |
| 점(POINT) | 중심점 수집 |
| 원(CIRCLE) | 건너뜀 (곡면) |
| 면(SURFACE) | 건너뜀 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "로드된 Body 노드가 없습니다." | 모델 미로드 또는 부재가 없음 | [파일 열기]로 모델을 다시 열고 부재가 보이는지 확인 |
| "Osnap 수집 중 오류: {상세 메시지}" | 처리 중 내부 오류 | 메시지를 담당자에게 전달. 일부만 수집됐을 수 있음 |
