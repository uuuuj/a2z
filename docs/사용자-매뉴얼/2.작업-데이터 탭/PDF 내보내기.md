# PDF 내보내기

## 🟢 한 줄로
방금 만든 2D 도면을 **벡터 PDF 파일**로 저장합니다. CAD에서도 깨지지 않게 선이 또렷합니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: 작업
- **라벨**: [PDF 내보내기]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지
- [ ] 2D 도면이 이미 생성된 상태인지 — 화면 오른쪽에 2D 도면 영역이 보여야 함 ([2D 생성](./2D%20생성.md) 또는 [가공도 출력](./가공도%20출력.md) 먼저 실행)

## ▶️ 누르면 이런 순서로 일어납니다
1. **모델 열림 여부 확인** — 안 열려 있으면 [에러 ①]
2. **2D 도면 존재 확인** — 2D 도면이 생성 안 된 상태면 [에러 ②]
3. **저장 대화창 열림** — 기본 파일명 예: `2D_Drawing_20260414_153045`
4. **저장 위치/파일명 지정** — 취소하면 저장 안 됨
5. **선택 테두리(노란 박스) 제거** — CAD 호환을 위해 화면상 강조 표시 정리
6. **벡터 PDF로 내보내기** — 실제 파일 저장
7. **완료 팝업** — "PDF 파일로 저장되었습니다."

## 🔀 분기 상황
### ① 저장 대화창에서
| 상태 | 처리 |
|---|---|
| [저장] 클릭 | 5~7단계 진행 |
| [취소] 또는 닫기 | 조용히 종료 (파일 생성 안 됨) |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "먼저 모델을 열어주세요." | 3D 모델 미로드 | [파일 열기]로 모델을 먼저 여세요 |
| "먼저 '2D 생성' 버튼으로 2D 도면을 생성해주세요." | 2D 도면이 아직 만들어지지 않음 | [2D 생성] 또는 [가공도 출력] 버튼을 먼저 누르세요 |
| "PDF 저장 중 오류: {상세 메시지}" | 파일 쓰기 실패 (권한·경로·용량 문제 등) | 저장 위치 권한 확인, 같은 이름 파일이 열려 있지 않은지 확인 |
