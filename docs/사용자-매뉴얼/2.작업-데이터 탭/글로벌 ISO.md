# 글로벌 ISO

## 🟢 한 줄로
모델을 **등각(입체) 방향**에서 바라보는 뷰로 전환합니다. 현재 상태에 따라 "도면 시트/선택 부재/전체 모델" 중 적절한 범위에 맞춰 카메라가 자동으로 조정되고, 부재마다 번호 풍선이 표시됩니다.

## 📍 버튼 위치
- **탭**: (좌측 상단 글로벌 뷰 바 — 모든 탭 공통)
- **라벨**: [ISO]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지
- [ ] 도면 시트 전용 ISO를 보려면 도면정보 탭에서 시트를 선택해 둔 상태여야 함

## ▶️ 누르면 이런 순서로 일어납니다
1. **현재 상태 판정** — [분기 ①]
2. **해당 범위로 카메라를 ISO 각도로 이동**
3. **은선(점선) 모드 적용** — 가려진 모서리가 점선으로 표시됨
4. **해당 범위의 부재마다 번호 풍선 표시**

## 🔀 분기 상황
### ① 어떤 범위로 ISO 뷰가 적용되나요? (우선순위 순)
| 조건 | 처리 |
|---|---|
| 도면정보 탭이 열려 있고 시트를 선택한 상태 | 해당 시트에 포함된 부재 기준으로 ISO 뷰 |
| X-Ray로 선택한 부재가 있음 | 선택한 부재 기준 |
| 그 외 | 전체 모델 기준 |

### ② 풍선은 어떤 부재에 달리나요?
| 경로 | 풍선 대상 |
|---|---|
| 도면 시트 경로 | 시트에 속한 부재 |
| 선택 부재 경로 | 선택 부재 전체 |
| 전체 모델 경로 | BOM 전체 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "뷰 전환 중 오류: {상세 메시지}" | 처리 중 내부 오류 | 메시지를 담당자에게 전달. 뷰가 부분적으로만 바뀌었을 수 있음 |
