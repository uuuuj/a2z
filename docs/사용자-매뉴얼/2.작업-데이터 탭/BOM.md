# BOM

## 🟢 한 줄로
열려 있는 3D 모델에서 **부재 목록**(이름, 크기, 홀 정보 등)을 모아 BOM 목록에 채워 넣습니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: 작업
- **라벨**: [BOM]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지 ([파일 열기](../1.기본-작업/파일%20열기.md) 먼저)
- [ ] 수집하고 싶은 부재가 화면에 보이도록 가시성 설정

## ▶️ 누르면 이런 순서로 일어납니다
1. **모델의 모든 부재 노드를 순회** — 부재 하나하나를 모델에서 꺼냅니다
2. **부재마다 크기(바운딩박스) 계산** — 가로·세로·높이 치수 산출
3. **원형 홀 감지** — 부재 속에 원기둥 형태 공간이 있으면 "홀"로 등록
4. **장공(슬롯홀) 감지** — 길쭉한 구멍 형태도 별도로 등록
5. **BOM 목록에 기록** — 각 부재를 한 행씩 BOM 데이터 목록에 추가
6. **화면의 BOM 목록 갱신** — 오른쪽 BOM 데이터 창에 행이 표시됨
7. **결과 알림** — "수집된 부재 개수" 메시지 팝업, 또는 실패 알림

## 🔀 분기 상황
### ① 홀이 발견되면
| 상태 | 처리 |
|---|---|
| 부재 안에 실린더 형태 공간 있음 | 원형 홀로 등록(직경·위치 저장) |
| 슬롯(장공) 형태 감지 | 별도 슬롯홀로 등록 |
| 홀 없음 | 홀 정보는 빈 리스트 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "로드된 모델이 없거나 BOM 수집에 실패했습니다." | 모델이 안 열려 있거나 부재 노드가 0개 | [파일 열기]로 먼저 모델을 열고, 부재가 실제로 존재하는 파일인지 확인 |
