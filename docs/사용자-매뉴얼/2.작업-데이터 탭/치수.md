# 치수

## 🟢 한 줄로
**지금 화면에 보이는 부재만** 대상으로 BOM·특징점·치수를 다시 뽑습니다. 도면 시트를 선택한 상태면 시트의 기준 부재명이 화면에 함께 표시됩니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: 작업
- **라벨**: [치수]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지
- [ ] 치수를 다시 뽑고 싶은 부재들이 **지금 화면에 보이는 상태**인지 (가려진 부재는 제외됨)

## ▶️ 누르면 이런 순서로 일어납니다
1. **X-Ray 선택 목록 비우기** — 이전 선택 상태 초기화
2. **이전 주석·치수·보조선 모두 제거**
3. **BOM 재수집** — 현재 부재 목록을 새로 모음
4. **화면에 보이는 부재만 골라서 X-Ray 선택 목록에 넣음** — 이후 다른 작업에서 "지금 보이는 부재만" 범위가 됨
5. **특징점 재수집** — 꼭짓점·모서리점 등을 다시 계산
6. **특징점 개수 확인** — 0개면 [에러 ①]
7. **부재명 오버레이 갱신** — [분기 ①]
8. **기존 치수 표시 제거**
9. **X·Y·Z 축별 체인 치수 새로 만들기**
10. **치수 목록(화면 우측) 갱신**

## 🔀 분기 상황
### ① 부재명 오버레이는 어떻게 표시되나요?
| 상태 | 오버레이에 나오는 값 |
|---|---|
| 도면 시트 목록에서 행을 선택해 둔 경우 | 해당 시트의 기준 부재명 |
| 시트 선택 없음 | 빈 텍스트 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "먼저 Osnap 좌표를 수집해주세요." | 현재 뷰에 부재가 없거나 특징점이 하나도 모이지 않음 | 부재가 화면에 보이도록 가시성 확인 후 재시도. 또는 [Osnap] 버튼을 먼저 눌러보세요 |
