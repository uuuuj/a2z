# 가공도 출력

## 🟢 한 줄로
BOM 목록에서 **선택한 부재 1개**의 가공용 상세 도면을 만듭니다. 최장축이 가로가 되도록 카메라를 회전하고, 판재(PAD/PLATE)이면 두께가 맞게 자동 정렬합니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: BOM 데이터
- **라벨**: [가공도 출력]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지
- [ ] BOM 목록에 부재가 채워져 있는지 ([BOM](./BOM.md) 먼저)
- [ ] BOM 목록에서 부재를 **정확히 1개 선택**했는지

## ▶️ 누르면 이런 순서로 일어납니다
1. **BOM 선택 확인** — 부재가 선택되지 않았으면 [에러 ①]
2. **이전 치수·풍선·보조선 모두 정리**
3. **X-Ray 모드 해제**
4. **선택한 부재만 표시** — 나머지 부재는 전부 숨김
5. **부재 크기 분석** — 가로·세로·높이 비교해 최장축 결정
6. **판재(PAD/PLATE) 판별** — 부재 규격 정보로 판단 [분기 ①]
7. **뷰 방향 결정** — 최장축이 가로가 되도록, 두께 방향이 Z+가 되도록
8. **카메라 배치**
9. **설치 방향 속성 적용** — [분기 ②]
10. **특징점 수집**
11. **치수 생성**
12. **은선(점선) 모드 + 번호 풍선 + 보조선** 적용
13. **2D 도면 완성** — 화면 오른쪽에 가공도 표시

## 🔀 분기 상황
### ① 판재(PAD/PLATE) 판별
| 상태 | 처리 |
|---|---|
| 부재 규격 정보에 "PAD" 또는 "PLATE" 포함 | 두께 방향을 별도 판정해 정면뷰 설정 |
| 그 외 일반 부재 | 최장축=가로, 차장축=세로로 뷰 설정 |

### ② 설치 방향 속성(ORIENTATION)이 있으면
| 상태 | 처리 |
|---|---|
| 부재 속성에 ORIENTATION 있음 + 파싱 성공 | 저장된 각도로 추가 회전 |
| 없거나 파싱 실패 | 기본 회전만 |

### ③ 특징점이 수집되지 않으면
| 상태 | 처리 |
|---|---|
| 특징점 0개 | 치수 없이 도면만 생성 |
| 특징점 있음 | 치수 자동 배치 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "BOM 리스트에서 부재를 선택하세요." | BOM 목록에서 아무 행도 선택되지 않음 | BOM 목록에서 원하는 부재 1개를 클릭한 뒤 다시 누르세요 |

> ⚠️ 가공도 생성 중 오류가 나면 일부 부재만 보이는 상태로 남을 수 있습니다. **BOM 목록을 더블클릭하거나 글로벌 뷰(ISO/X/Y/Z)** 버튼을 누르면 전체 가시성이 복구됩니다.
