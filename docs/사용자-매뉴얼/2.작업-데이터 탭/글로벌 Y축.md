# 글로벌 Y축

## 🟢 한 줄로
모델을 **Y축(+) 방향**에서 정면으로 바라보는 뷰로 전환하고, **Y방향 치수만** 표시합니다. (번호 풍선은 표시되지 않음)

## 📍 버튼 위치
- **탭**: (좌측 상단 글로벌 뷰 바 — 모든 탭 공통)
- **라벨**: [Y축]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지
- [ ] Y방향 치수를 미리 만들어 둔 상태이면 이 버튼으로 바로 확인 가능

## ▶️ 누르면 이런 순서로 일어납니다
1. **현재 상태 판정** — [분기 ①]
2. **해당 범위로 카메라를 Y+ 방향에 배치** (정면뷰)
3. **은선(점선) 모드 적용**
4. **Y방향 체인 치수 표시** — 이전에 표시된 풍선/다른 축 치수는 정리됨

## 🔀 분기 상황
### ① 어떤 범위로 뷰가 적용되나요? (우선순위 순)
| 조건 | 처리 |
|---|---|
| 도면정보 탭이 열려 있고 시트를 선택한 상태 | 해당 시트 부재 기준 |
| X-Ray로 선택한 부재가 있음 | 선택 부재 기준 |
| 그 외 | 전체 모델 기준 |
