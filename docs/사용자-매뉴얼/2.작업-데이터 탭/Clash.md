# Clash

## 🟢 한 줄로
부재끼리 **겹치거나 충돌하는 지점**(간섭)을 찾는 검사를 시작합니다. 결과는 조금 기다리면 자동으로 Clash 목록에 채워집니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: 작업
- **라벨**: [Clash]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지
- [ ] 화면에 부재가 2개 이상 보이는지 (1개만 있으면 비교할 대상이 없음)

## ▶️ 누르면 이런 순서로 일어납니다
1. **Clash 목록 초기화** — 이전 간섭 검사 결과 삭제
2. **부재 노드 전체 획득** — 모델 안의 부재들을 가져옴
3. **대상 부재 범위 결정** — [분기 ①]
4. **검사기 초기화** — 내부 간섭 검사기 비움
5. **부재 쌍 등록** — 대상 부재들의 모든 쌍(A-B, A-C...)을 검사 대상으로 추가
6. **검사 파라미터 설정** — 허용 간격·관통 허용치 1mm
7. **비동기 간섭 검사 시작** — 백그라운드에서 계산
8. **"간섭검사를 시작합니다..." 팝업** — 진행 중 알림
9. **검사 완료되면 자동 알림** — 결과가 Clash 목록에 행 단위로 채워지고, 간섭 지점에는 삼각형 심볼이 표시됨

## 🔀 분기 상황
### ① 어떤 부재끼리 검사하나요?
| 상태 | 검사 대상 |
|---|---|
| X-Ray로 선택한 부재가 있음 | 선택한 부재들만 |
| 선택 없이 화면에 보이는 부재만 설정 | 현재 보이는 부재만 |
| 필터 결과가 0개 | 모델 전체 부재 (fallback) |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "로드된 모델이 없거나 간섭검사 시작에 실패했습니다." | 모델 미로드 / 대상 부재 0~1개 / 검사 시작 실패 | 모델이 제대로 열렸는지, 부재가 2개 이상 보이는지 확인 후 재시도 |
