# A2Z-HYI 사용자 매뉴얼

> **"2D 제작도 생성기"** 앱의 모든 버튼/액션에 대한 사용자용 설명서.
> 각 버튼을 누르면 무엇이, 어떤 순서로 일어나는지 알 수 있도록 작성.

## 📚 이 매뉴얼 사용법

- 버튼 이름을 알고 있다면 아래 목차에서 바로 찾으세요
- 탭별로 분류되어 있어 앱 화면과 동일한 구조로 탐색 가능
- 각 문서 마지막의 "🔗 이어지는 작업" 링크로 관련 버튼을 따라가며 학습 가능
- "🔬 자세히 보기" 섹션에는 개발자용 상세 문서 링크 제공

## 🔍 자주 혼동되는 버튼

| 이 버튼 | vs 이 버튼 | 차이 |
|---|---|---|
| 작업/데이터 탭의 [BOM] | 도면정보 탭의 [BOM 수집] | 전자는 부재 전체 목록 수집, 후자는 선택 시트 그룹별 정리 |
| 작업/데이터 탭의 [2D 생성] | 도면정보 탭의 [2D 출력] | 전자는 BOM 전체 한 장, 후자는 선택 시트 한 장 |
| 작업/데이터 탭의 [가공도 출력] | 도면정보 탭의 [가공도 일괄 출력] | 전자는 선택 부재 1개, 후자는 여러 가공도 시트 한꺼번에 |
| 작업/데이터 탭의 [치수] | 1.기본 작업의 [치수 추출] | 전자는 현재 뷰 기준 재계산, 후자는 전체 자동 파이프라인 실행 |
