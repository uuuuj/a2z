# 파일 열기

## 🟢 한 줄로
3D 모델 파일(.vizx 또는 .viz)을 프로그램으로 불러옵니다. 새 파일을 열면 이전에 작업하던 내용은 모두 비워집니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: 작업
- **라벨**: [파일 열기]

## ✅ 누르기 전 확인할 것
- [ ] 열고 싶은 `.vizx` 또는 `.viz` 파일 경로를 알고 있는지
- [ ] 이전 작업 내용(BOM, 치수, Clash 등)은 파일을 열면 **전부 초기화**됩니다 — 저장이 필요하면 먼저 PDF로 내보내세요
- [ ] VIZCore3D 라이선스가 유효한지

## ▶️ 누르면 이런 순서로 일어납니다
1. **파일 선택창 열림** — `.vizx`, `.viz` 확장자만 보이도록 필터링됩니다
2. **파일 선택** — 취소하면 아무 일도 일어나지 않고 끝납니다
3. **파일 존재 확인** — 경로가 틀리거나 파일이 사라졌으면 [에러 ①]
4. **기존 작업 내용 전부 비우기** — BOM 목록, Clash 목록, 특징점 목록, 치수 목록, 시트 목록 등 모두 초기화
5. **이전 주석·치수·보조선 정리** — 화면에 그려졌던 치수나 도형 모두 지움
6. **모델 로드** — 실제로 3D 모델을 읽어들입니다
7. **화면에 꽉 차게 맞춤** — 모델 전체가 한눈에 보이도록 확대/축소
8. **부재 외곽선 강조** — 부재 테두리가 초록색으로 또렷하게 보이게 설정
9. **내부 부재 매핑 구축** — 이후 작업(BOM 수집 등)이 잘 되도록 부재 이름과 번호를 연결

## 🔀 분기 상황
### ① 파일 선택창에서 취소를 누른 경우
| 상태 | 결과 |
|---|---|
| 파일 선택창에서 [취소] 클릭 | 아무 일도 일어나지 않음 (기존 작업 내용 유지) |
| 파일 선택 후 [열기] 클릭 | 초기화 → 로드 진행 |

### ② 로드 결과
| 상태 | 결과 |
|---|---|
| 로드 성공 | 3D 뷰어에 모델이 표시되고 이후 작업 가능 |
| 로드 실패 | [에러 ②] — **이미 초기화는 끝난 상태**라 이전 모델은 돌아오지 않음 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "선택한 파일이 존재하지 않습니다." | 파일 경로가 틀렸거나 파일이 삭제/이동됨 | 파일 위치를 다시 확인하고 선택하세요 |
| "파일 열기 실패 ... 라이선스나 파일 형식 확인" | 라이선스 문제 또는 지원하지 않는 파일 형식 | VIZCore3D 라이선스 상태 확인, 파일 확장자가 `.vizx`·`.viz`인지 확인 |
| "파일 열기 중 예외 발생: {상세 메시지}" | 파일 자체가 손상되었거나 내부 처리 오류 | 메시지 내용을 담당자에게 전달. 파일을 다시 받아보세요 |

> ⚠️ 에러가 발생해도 **기존 작업 내용은 이미 비워진 상태**입니다. 이전 모델로 돌아가려면 그 파일을 다시 열어야 합니다.
