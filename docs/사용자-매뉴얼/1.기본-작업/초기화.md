# 초기화

## 🟢 한 줄로
현재 열려 있는 파일을 **처음 열었을 때 상태로 되돌립니다**. BOM·치수·풍선·Clash·도면 시트 등 지금까지 한 모든 작업이 사라지고, 같은 파일이 다시 로드됩니다.

## 📍 버튼 위치
- **위치**: 3D 뷰어 위쪽, 글로벌 뷰 버튼 줄의 **제일 왼쪽** (ISO 버튼 왼쪽)
- **라벨**: [초기화]
- **색상**: 회색 (ISO/X/Y/Z와 구분됨)

## ✅ 누르기 전 확인할 것
- [ ] 이미 파일이 열려 있는지 (안 열려 있으면 "먼저 파일을 열어주세요." 경고가 뜨고 끝)
- [ ] **지금까지 작업한 내용이 전부 사라져도 괜찮은지** — 저장하지 않은 치수/도면/풍선 조정이 있으면 되돌릴 수 없습니다
- [ ] 같은 파일을 다시 읽기만 하므로, 다른 파일로 바꾸고 싶다면 [파일 열기](./파일%20열기.md)를 사용하세요

## ▶️ 누르면 이런 순서로 일어납니다
1. **가드 체크** — 파일이 안 열려 있으면 경고창 띄우고 끝 (분기 ①)
2. **확인 다이얼로그** — "모든 작업 내용이 초기화되고 현재 파일이 처음 열었을 때 상태로 다시 로드됩니다. 계속하시겠습니까?" — [아니오] 누르면 아무 일도 안 일어나고 끝
3. **작업 내용 전부 비우기** — BOM/Clash/Osnap/치수/도면 시트 목록 + 풍선 수동 조정 이력 모두 삭제
4. **3D에 그려진 치수·보조선·풍선 지우기** — 뷰어 화면 초기화
5. **같은 파일 재로드** — 파일 다이얼로그는 뜨지 않음. 현재 파일 경로로 다시 열기
6. **화면 맞춤** — 모델 전체가 보이도록 확대/축소
7. **외곽선 강조 재적용** — 부재 테두리 초록색

## 🔀 분기 상황
### ① 파일이 안 열려 있을 때
| 상태 | 결과 |
|---|---|
| 아직 파일을 한 번도 안 열었거나, 모델이 닫힌 상태 | 경고창 "먼저 파일을 열어주세요." → 끝 |
| 파일이 정상 열림 | 다음 단계 진행 |

### ② 확인 다이얼로그 응답
| 상태 | 결과 |
|---|---|
| [예] | 초기화 + 재로드 진행 |
| [아니오] 또는 창 닫기 | 아무 일도 일어나지 않음 (기존 작업 유지) |

### ③ 재로드 결과
| 상태 | 결과 |
|---|---|
| 성공 | 모델이 처음 상태로 표시됨. 다시 BOM 수집부터 시작 가능 |
| 실패 | [에러 ②] — **작업 내용은 이미 초기화된 상태**라 복구 불가. [파일 열기]로 다시 열어야 함 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "먼저 파일을 열어주세요." | 파일이 안 열려 있음 | [파일 열기] 먼저 실행 |
| "파일 재로드에 실패했습니다. 파일을 다시 열어주세요." | 파일이 이동·삭제되었거나 라이선스 문제 | [파일 열기]로 수동 재선택 |
| "초기화 중 예외 발생: {상세 메시지}" | 내부 처리 오류 | 메시지를 담당자에게 전달. [파일 열기]로 복구 시도 |

> ⚠️ 재로드 실패 시 **작업 내용은 이미 비워진 상태**입니다. [파일 열기]로 파일을 다시 선택해야 합니다.

## 💡 이럴 때 쓰세요
- 여러 부재 중 하나만 남기고 치수 추출했는데 다시 전체를 대상으로 작업하고 싶을 때
- 풍선 위치를 여러 번 수동 조정했는데 원상태로 돌리고 싶을 때
- 시트 분할 결과가 마음에 안 들어서 다시 하고 싶을 때
- X-Ray로 일부 부재만 보이게 해 놨는데 전체 모델로 돌아가고 싶을 때

## 🆚 비슷한 버튼과의 차이
| 이 버튼 | vs | 차이 |
|---|---|---|
| [초기화] | [파일 열기] | 같은 파일을 다시 여는 용도. 파일 선택 다이얼로그가 뜨지 않음 |
| [초기화] | [Clash 전체 보기] | 전자는 **모든 데이터까지** 비움. 후자는 X-Ray와 색상만 복원 |
| [초기화] | [풍선 위치 조정] 안의 [전체 초기화] | 전자는 **모델 전체**를 리셋. 후자는 **풍선 수동 조정 오프셋만** 리셋 |
