# 치수 추출

## 🟢 한 줄로
버튼 하나로 **BOM 수집 → 특징점 수집 → X/Y/Z 치수 생성 → 간섭 검사**를 한 번에 끝내는 자동 파이프라인 버튼입니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: 작업
- **라벨**: [치수 추출]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 이미 열려 있는지 (파일 열기를 먼저 수행)
- [ ] **3D 뷰에 부재가 "하나만" 표시되거나 "하나만" 선택된 상태** — 여러 부재가 보이는 상태에서는 안전을 위해 실행이 차단됩니다 (2026-04-22 T-023 이후)
  - 단일화 방법: 도면 시트 목록 / BOM 테이블에서 하나 선택 · 모델트리에서 원하는 부재만 체크박스 on · 3D 뷰에서 단일 부재 클릭

## ▶️ 누르면 이런 순서로 일어납니다
1. **모델 열림 여부 확인** — 안 열려 있으면 [에러 ①]
1-2. **단일 부재 조건 확인** (2026-04-22 추가) — 표시 중 부재 수와 선택 중 부재 수를 계산. 둘 다 1이 아니면 [에러 ③] 팝업 후 종료
2. **"처리 중..." 오버레이 표시** — 3D 뷰어 중앙에 라벨이 뜨고 각 단계 진입마다 메시지가 바뀝니다 (T-018)
3. **BOM 재수집** — 현재 화면에 보이는 부재 기준으로 부재 목록을 다시 모읍니다. (가시성이 반영되도록 항상 새로 수집)
3. **BOM 개수 확인** — 수집된 부재가 0개면 [에러 ②]
4. **특징점(꼭짓점·중점 등) 수집** — 각 부재의 모서리·점 정보를 가져옵니다
5. **좌표 병합** — 거의 같은 위치(0.5mm 이내)의 점들을 하나로 합칩니다
6. **X·Y·Z 축별 체인 치수 계산** — 각 방향으로 이어진 치수를 자동 생성
7. **치수 목록 갱신** — 치수 목록(No/축/뷰 이름/거리/시작점/끝점)이 화면에 표시됨
8. **3D 뷰어에 치수 표시** — 축별로 서로 겹치지 않도록 간격을 둬서 그립니다
9. **간섭 검사 시작** — 부재끼리 겹치거나 충돌하는 곳을 찾는 비동기 검사 시작
10. **검사 완료 대기** — "간섭검사를 시작합니다..." 팝업 표시 후 백그라운드 진행. 완료되면 별도 알림이 자동으로 나타납니다

## 🔀 분기 상황
### ① 특징점 수집이 실패한 경우
| 상태 | 처리 |
|---|---|
| 특징점을 정상적으로 모았음 | 5~8단계까지 수행 후 간섭 검사 |
| 특징점이 0개이거나 실패 | 치수 생성은 건너뛰고 **간섭 검사만** 실행 |

### ② 대상 부재 범위
| 상태 | 처리 |
|---|---|
| X-Ray로 선택한 부재가 있음 | 선택된 부재만 대상 |
| 선택 없음 | 화면에 보이는 부재로 필터, 없으면 전체 부재 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "먼저 파일을 열어주세요." | 3D 모델이 로드되지 않은 상태 | [파일 열기] 버튼으로 `.vizx`·`.viz` 파일을 먼저 여세요 |
| "BOM 데이터를 수집할 수 없습니다." | 모델에 부재가 없거나, 가시성 설정 때문에 대상이 0개 | 부재가 화면에 보이도록 가시성을 켜고 다시 누르세요 |
| **③ "치수 추출은 3D View에 부재가 하나만 표시되거나 선택된 상태에서 가능합니다. 현재: 표시 N개, 선택 M개"** (2026-04-22 신설) | 3D 뷰에 여러 부재가 떠 있거나, 또는 보이는 부재가 0개인 상태 | 도면 시트 목록/BOM 테이블에서 하나 클릭, 모델트리에서 원하는 부재만 체크, 3D 뷰에서 단일 부재 클릭 중 하나로 단일화 |
| "치수 추출 중 오류: {상세 메시지}" | 처리 중 내부 오류 발생 | 메시지 내용을 담당자에게 전달. 일부 치수만 생성됐을 수 있음 |
