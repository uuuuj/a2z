# 치수 추출

## 🟢 한 줄로
버튼 하나로 **BOM 수집 → 특징점 수집 → X/Y/Z 치수 생성 → 간섭 검사**를 한 번에 끝내는 자동 파이프라인 버튼입니다.

## 📍 버튼 위치
- **탭**: 작업/데이터
- **그룹**: 작업
- **라벨**: [치수 추출]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 이미 열려 있는지 (파일 열기를 먼저 수행)
- [ ] 모델에 부재가 들어 있는지 (빈 모델이면 BOM이 0개)
- [ ] 특정 부재만 대상으로 하고 싶다면 미리 선택(X-Ray 선택) 또는 원하는 부재만 화면에 보이도록 가시성 설정

> 향후 **"하나의 STRU 단위만 치수추출 허용"** 가드가 추가될 예정입니다 (T-023, 현재 비활성). 활성화되면 여러 STRU가 동시에 보이는 상태에서는 실행이 차단됩니다.

## ▶️ 누르면 이런 순서로 일어납니다
1. **모델 열림 여부 확인** — 안 열려 있으면 [에러 ①]
2. **"처리 중..." 오버레이 표시** — 3D 뷰어 중앙에 라벨이 뜨고 각 단계 진입마다 메시지가 바뀝니다
3. **BOM 재수집** — 현재 화면에 보이는 부재 기준으로 부재 목록을 다시 모읍니다 ("BOM 수집 중...")
3. **BOM 개수 확인** — 수집된 부재가 0개면 [에러 ②]
4. **특징점(꼭짓점·중점 등) 수집** — 각 부재의 모서리·점 정보를 가져옵니다
5. **좌표 병합** — 거의 같은 위치(0.5mm 이내)의 점들을 하나로 합칩니다
6. **X·Y·Z 축별 체인 치수 계산** — 각 방향으로 이어진 치수를 자동 생성
7. **치수 목록 갱신** — 치수 목록(No/축/뷰 이름/거리/시작점/끝점)이 화면에 표시됨
8. **3D 뷰어에 치수 표시** — 축별로 서로 겹치지 않도록 간격을 둬서 그립니다
9. **간섭 검사 시작** — 부재끼리 겹치거나 충돌하는 곳을 찾는 비동기 검사 시작
10. **검사 완료 대기** — "간섭검사를 시작합니다..." 팝업 표시 후 백그라운드 진행. 완료되면 별도 알림이 자동으로 나타납니다

## ⚙️ 내부 흐름 (2026-04-22 이후)

치수 추출 버튼을 누르면 다음 순서로 진행됩니다:
1. BOM 수집 ("BOM 수집 중...")
2. **간섭 검사 먼저 실행** ("간섭검사 실행 중...") — 기존엔 치수 뒤였지만 순서 변경
3. 간섭 결과가 나오면 **부재들이 한 덩어리로 연결되어 있는지 판정**
   - 떨어진 부재가 하나라도 있으면 [에러 ③] 팝업 후 종료 (치수 안 뜸)
   - 모두 연결되어 있으면 다음 단계
4. 특징점(Osnap) 수집 ("Osnap 수집 중...")
5. X/Y/Z 체인 치수 계산 ("치수 계산 중...")
6. 치수 목록 갱신 + 3D 뷰에 치수 표시
7. 요약 팝업 (BOM/Osnap/치수/Clash 개수)
8. 도면 시트 목록 + BOM 테이블 자동 채움 (Sheet 1 기준)

## 🔀 분기 상황
### ① 특징점 수집이 실패한 경우
| 상태 | 처리 |
|---|---|
| 특징점을 정상적으로 모았음 | 치수 계산 + 3D 표시 수행 |
| 특징점이 0개이거나 실패 | 치수는 비어 있지만 요약 팝업과 시트 생성은 진행 |

### ② 연결성 판정 (새 동작)
| 상태 | 처리 |
|---|---|
| 모든 부재가 한 덩어리 | 통과, 치수 계산 진행 |
| 떨어진 부재 있음 (간섭 없는 독립 덩어리 2개 이상) | [에러 ③] 차단, 치수도 시트도 만들지 않음 |
| 부재가 1개뿐 | 단일 부재로 간주, 판정 스킵하고 통과 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "먼저 파일을 열어주세요." | 3D 모델이 로드되지 않은 상태 | [파일 열기] 버튼으로 `.vizx`·`.viz` 파일을 먼저 여세요 |
| "BOM 데이터를 수집할 수 없습니다." | 모델에 부재가 없거나, 가시성 설정 때문에 대상이 0개 | 부재가 화면에 보이도록 가시성을 켜고 다시 누르세요 |
| **③ "치수 추출은 모든 부재가 하나의 덩어리로 연결되어 있을 때만 가능합니다. 현재: 서로 연결되지 않은 부재 그룹 N개 발견"** (2026-04-22 신설) | 화면에 서로 맞닿지 않은(간섭 없는) 부재가 포함되어 있음 | 떨어진 부재를 모델트리 체크박스로 숨기거나, 한 덩어리만 남기고 다시 치수 추출 |
| "치수 추출 중 오류: {상세 메시지}" | 처리 중 내부 오류 발생 | 메시지 내용을 담당자에게 전달. 일부 치수만 생성됐을 수 있음 |
| "간섭검사 결과 처리 중 오류: {상세 메시지}" | 간섭 검사 결과 수집·판정 중 오류 | 메시지 담당자에 전달. 오버레이는 자동 해제됨 |
