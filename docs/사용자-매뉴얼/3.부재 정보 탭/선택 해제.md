# 선택 해제

## 🟢 한 줄로
3D 뷰어의 부재 선택과 부재 정보 탭의 속성 테이블을 **동시에 싹 비웁니다**.

## 📍 버튼 위치
- **탭**: 부재 정보
- **그룹**: 부재 정보 버튼 그룹 (`panelAttributeButtons`)
- **라벨**: [선택 해제]

## ✅ 누르기 전 확인할 것
- [ ] 없음 — 언제든 눌러도 안전합니다

## ▶️ 누르면 이런 순서로 일어납니다
1. **3D 뷰어 선택 풀기** — 현재 선택된 모든 부재의 선택 상태를 해제합니다
2. **속성 테이블 비우기** — 부재 정보 탭 테이블의 모든 행을 지웁니다
3. **안내 라벨 초기화** — 테이블 위 라벨이 "3D 뷰어에서 부재를 선택하세요"로 되돌아옵니다
4. **내부 상태 리셋** — 내부적으로 추적하던 선택 부재 번호를 초기화합니다 (-1)
5. **완료** — 깨끗한 상태. 다음에 새로 부재를 클릭하면 속성이 다시 채워집니다

## 🔀 분기 상황
없음. 선택된 것이 없어도 무해하게 실행됩니다.

## ⚠️ 에러 메시지와 대처
없음. 팝업 없이 조용히 동작합니다.

## 🔗 이어지는 작업
- 새로운 부재 속성을 보려면 → [3D 뷰어에서 부재 클릭](./3D%20뷰어에서%20부재%20클릭.md)
- 다른 작업 탭으로 넘어가려면 → 좌측 탭을 **작업/데이터** 또는 **도면정보**로 전환
