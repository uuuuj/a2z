# UDA 추가

## 🟢 한 줄로
선택한 부재에 **새로운 부재 속성(키/값 한 쌍)** 을 추가합니다.

> 💡 "UDA"는 사용자 정의 부재 속성을 뜻합니다. 이 문서에서는 **부재 속성**이라고 부릅니다.

## 📍 버튼 위치
- **탭**: 부재 정보
- **그룹**: 부재 정보 버튼 그룹 (`panelAttributeButtons`)
- **라벨**: [UDA 추가]

## ✅ 누르기 전 확인할 것
- [ ] 3D 뷰어에서 속성을 추가할 **부재를 먼저 클릭**해 둔 상태인지
- [ ] 속성 테이블 상단에 `[번호] 부재이름` 라벨이 보이는지

## ▶️ 누르면 이런 순서로 일어납니다
1. **부재 선택 확인** — 선택된 부재가 없으면 팝업 띄우고 종료 (→ 에러)
2. **입력 다이얼로그 표시** — 키와 값을 입력하는 창이 뜹니다 (키 빈칸 / 값 빈칸)
3. **사용자 입력** — 키에 속성 이름, 값에 속성 값을 입력
4. **취소 누르면** 종료
5. **키 유효성 검사** — 키가 빈 값이면 다이얼로그 내부에서 경고 후 종료
6. **부재에 속성 추가** — 해당 부재에 새 키/값을 저장
7. **테이블 갱신** — 부재 정보 탭 테이블의 부재 속성 섹션에 방금 추가한 항목이 새 행으로 표시
8. **완료 팝업** — 추가 성공 알림

## 🔀 분기 상황
### ① 다이얼로그 결과
| 상태 | 처리 |
|---|---|
| 확인 + 키 입력함 | 속성 추가 진행 |
| 확인 + 키 빈칸 | 다이얼로그가 경고 후 종료 |
| 취소 | 아무것도 안 하고 종료 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "부재를 먼저 선택하세요." | 3D 뷰어에서 부재를 선택 안 함 | [3D 뷰어에서 부재 클릭](./3D%20뷰어에서%20부재%20클릭.md)으로 부재부터 선택하세요 |
| "UDA 추가 오류: {메시지}" | 저장 중 내부 오류 | 같은 이름의 키가 이미 있는지 확인(있다면 [UDA 편집](./UDA%20편집.md) 사용). 문제가 반복되면 재시도하거나 모델을 다시 열어주세요 |

## 🔗 이어지는 작업
- 방금 추가한 속성을 수정하려면 → [UDA 편집](./UDA%20편집.md)
- 잘못 추가했으면 → [UDA 삭제](./UDA%20삭제.md)
- 여러 건을 한꺼번에 넣고 싶으면 → [CSV 입력](./CSV%20입력.md)
- 현재 속성을 파일로 내보내려면 → [CSV 출력](./CSV%20출력.md)
