# CSV 입력

## 🟢 한 줄로
CSV 파일에 정리된 **부재 속성(키/값 목록)** 을 읽어 선택한 부재에 **한꺼번에** 추가하거나 기존 값을 갱신합니다.

> 💡 "UDA"는 사용자 정의 부재 속성을 뜻합니다. 이 문서에서는 **부재 속성**이라고 부릅니다.

## 📍 버튼 위치
- **탭**: 부재 정보
- **그룹**: 부재 정보 버튼 그룹 (`panelAttributeButtons`)
- **라벨**: [CSV 입력]

## ✅ 누르기 전 확인할 것
- [ ] 3D 뷰어에서 속성을 받을 **부재를 먼저 클릭**해 두었는지
- [ ] CSV 파일이 UTF-8 인코딩으로 저장되어 있는지 (한글 깨짐 방지)
- [ ] 파일 형식이 `Key,Value` 두 컬럼인지 (헤더 행은 자동 인식되어 건너뜀)

## ▶️ 누르면 이런 순서로 일어납니다
1. **부재 선택 확인** — 없으면 팝업 띄우고 종료
2. **파일 선택 다이얼로그** — CSV 파일을 고릅니다
3. **파일 읽기** — UTF-8로 모든 줄 읽어 옴
4. **빈 파일 검사** — 한 줄도 없으면 팝업 띄우고 종료
5. **헤더 자동 감지** — 첫 줄에 "key", "value", "속성" 같은 단어가 있으면 헤더로 보고 건너뜀
6. **줄마다 반복** — 각 줄을 순회:
   - 빈 줄 건너뜀
   - 쉼표 기준으로 분리 (큰따옴표로 감싼 값 안의 쉼표는 보존)
   - 컬럼 2개 미만이면 실패로 기록
   - 키가 빈 값이면 실패로 기록
   - **추가 시도** → 이미 있는 키면 **값 갱신으로 재시도**
   - 성공·실패 카운트
7. **테이블 갱신** — 부재 속성 섹션이 현재 상태로 다시 그려짐
8. **결과 팝업** — 성공 N건 / 실패 M건 표시 (실패 상세는 최대 10건 예시)

## 🔀 분기 상황
### ① 헤더 인식
| 첫 줄 내용 | 처리 |
|---|---|
| "key" / "value" / "속성" 단어 포함 | 헤더로 보고 데이터는 2번째 줄부터 |
| 그런 단어 없음 | 첫 줄부터 데이터로 간주 |

### ② 추가 → 갱신 자동 전환
| 상태 | 처리 |
|---|---|
| 같은 키 없음 | 새로 추가 → 성공 카운트 |
| 같은 키 이미 존재 | 추가 실패 후 값 갱신 자동 재시도 → 성공하면 성공 카운트 |
| 둘 다 실패 | 실패 카운트 + 오류 메시지 기록 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "부재를 먼저 선택하세요." | 3D 뷰어 선택 안 함 | [3D 뷰어에서 부재 클릭](./3D%20뷰어에서%20부재%20클릭.md)으로 부재 선택 |
| "CSV 파일이 비어있습니다." | 파일에 줄이 하나도 없음 | 파일 내용을 확인. 엑셀에서 저장 시 저장 형식이 "CSV UTF-8"인지 확인 |
| "CSV 파일 읽기 오류: {메시지}" | 파일을 열 수 없거나 잠겨 있음 | 엑셀에서 파일을 닫은 뒤 재시도. 또는 파일 경로에 특수 문자가 있는지 확인 |
| 결과 팝업에 실패 건수 표시 | 특정 줄이 형식 오류 | 팝업에 나온 오류 예시로 해당 줄 수정 (쉼표 누락 / 빈 키 등) 후 다시 가져오기 |

## 🔗 이어지는 작업
- 가져온 결과 확인 → 테이블에서 바로 보임
- 저장된 내용을 다시 내보내려면 → [CSV 출력](./CSV%20출력.md)
- 특정 항목 수정 → [UDA 편집](./UDA%20편집.md) / [UDA 삭제](./UDA%20삭제.md)
