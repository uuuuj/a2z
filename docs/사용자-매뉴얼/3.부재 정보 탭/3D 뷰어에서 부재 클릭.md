# 3D 뷰어에서 부재 클릭

## 🟢 한 줄로
3D 뷰어에서 부재를 마우스로 클릭하면, 해당 부재의 속성 정보(기본 정보·크기·부재 속성·형상 정보)가 **부재 정보 탭**에 자동으로 표시됩니다.

## 📍 버튼 위치
- **탭**: 부재 정보
- **상호작용**: 3D 뷰어 영역에서 부재를 마우스로 클릭
- **표시 위치**: 부재 정보 탭 내 속성 테이블(`dgvAttributes`)

> 이건 버튼이 아니라 **3D 뷰어에서 부재를 클릭하는 행위** 자체로 일어납니다. 부재 정보 탭을 열어 둔 상태에서 3D 뷰어의 부재를 클릭하면 속성이 나타납니다.

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지 ([파일 열기](../1.기본-작업/파일%20열기.md)로 먼저 엽니다)
- [ ] 좌측 탭이 **부재 정보** 탭으로 전환되어 있는지 (다른 탭이어도 선택은 되지만 테이블이 안 보입니다)

## ▶️ 누르면 이런 순서로 일어납니다
1. **3D 뷰어에서 부재 클릭** — 마우스 좌클릭으로 부재를 선택합니다
2. **선택된 부재 확인** — 앱이 방금 선택된 부재 하나를 집어 옵니다
3. **여러 개 선택했을 때도** — 다중 선택해도 **첫 번째 부재 하나만** 테이블에 표시합니다
4. **선택 라벨 갱신** — 속성 테이블 위 라벨이 `[인덱스번호] 부재이름`으로 바뀝니다
5. **속성 테이블 채우기** — 아래 4개 섹션이 순서대로 들어찹니다:
   - **기본 정보** — 인덱스 / 이름 / 종류 / 부모 경로
   - **크기 정보** — 최소/최대 XYZ 좌표, 크기, 중심점
   - **부재 속성 (UDA)** — 이 부재에 저장된 속성 키/값 (있는 것만 표시)
   - **형상 정보** — 재질, 면적, 부피 등 기하 정보
6. **완료** — 테이블에 부재 정보가 표시되어 확인·편집·내보내기 준비 끝

## 🔀 분기 상황
### ① 선택 유무에 따른 표시
| 상태 | 결과 |
|---|---|
| 부재를 클릭해서 선택함 | 첫 번째 부재의 속성이 테이블에 나타남 |
| 3D 뷰어 빈 공간 클릭 (선택 해제) | 테이블이 비워지고 라벨이 "3D 뷰어에서 부재를 선택하세요"로 초기화 |

### ② 여러 부재를 한꺼번에 선택한 경우
다중 선택(Ctrl+클릭 등)해도 **가장 먼저 잡힌 한 개**의 속성만 표시합니다. 여러 부재 속성을 한번에 비교하려면 별도로 하나씩 클릭해야 합니다.

## ⚠️ 에러 메시지와 대처
이 상호작용 자체는 팝업을 띄우지 않습니다. 단, 속성을 읽어 들이는 중 내부 오류가 나면 표시가 부분적으로만 될 수 있습니다(콘솔 로그에 기록). 표시가 비어 보이면 다시 클릭하거나 [선택 해제](./선택%20해제.md) 후 재시도 하세요.
