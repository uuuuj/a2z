# UDA 삭제

## 🟢 한 줄로
속성 테이블에서 선택한 **부재 속성 한 줄을 삭제**합니다. 삭제 전 확인 창이 한 번 뜹니다.

> 💡 "UDA"는 사용자 정의 부재 속성을 뜻합니다. 이 문서에서는 **부재 속성**이라고 부릅니다.

## 📍 버튼 위치
- **탭**: 부재 정보
- **그룹**: 부재 정보 버튼 그룹 (`panelAttributeButtons`)
- **라벨**: [UDA 삭제]

## ✅ 누르기 전 확인할 것
- [ ] 3D 뷰어에서 부재가 선택되어 있는지
- [ ] 속성 테이블에서 **부재 속성 섹션의 행 1개**를 선택해 두었는지

## ▶️ 누르면 이런 순서로 일어납니다
1. **부재 선택 확인** — 없으면 팝업 띄우고 종료
2. **행 선택 확인** — 테이블에서 행 안 고름 → 팝업 띄우고 종료
3. **부재 속성 행 판별** — 부재 속성(UDA) 섹션이 아니면 팝업 띄우고 종료
4. **키 꺼내기** — 선택 행의 키 추출
5. **확인 다이얼로그** — "삭제하시겠습니까?" Yes/No 팝업
6. **No 선택 시** 종료
7. **부재에서 속성 제거** — 해당 키를 모델에서 삭제
8. **테이블 갱신** — 삭제된 행이 테이블에서 사라짐
9. **완료 팝업** — 삭제 성공 알림

## 🔀 분기 상황
### ① 사용자 확인
| 선택 | 처리 |
|---|---|
| Yes | 삭제 실행 |
| No / 창 닫기 | 취소, 속성 그대로 유지 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "부재를 먼저 선택하세요." | 3D 뷰어 선택 안 함 | [3D 뷰어에서 부재 클릭](./3D%20뷰어에서%20부재%20클릭.md)으로 부재 선택 |
| "삭제할 UDA 행을 선택하세요." | 테이블 행 안 고름 | 테이블에서 지울 행을 클릭한 뒤 다시 누르세요 |
| "UDA 항목만 삭제할 수 있습니다..." | 기본 정보/크기/형상 섹션 행을 골랐음 | 부재 속성(UDA) 섹션의 행만 삭제 가능 |
| "UDA 삭제 오류: {메시지}" | 내부 오류 | 재시도. 계속 실패하면 모델을 다시 열어 보세요 |
