# CSV 출력

## 🟢 한 줄로
부재 정보 탭에 표시된 속성 테이블 전체(기본 정보·크기·부재 속성·형상 정보)를 CSV 파일로 저장합니다.

## 📍 버튼 위치
- **탭**: 부재 정보
- **그룹**: 부재 정보 버튼 그룹 (`panelAttributeButtons`)
- **라벨**: [CSV 출력]

## ✅ 누르기 전 확인할 것
- [ ] 3D 뷰어에서 부재를 **먼저 클릭해** 속성이 테이블에 표시된 상태인지
- [ ] 테이블에 최소 1개 이상의 행이 있는지

## ▶️ 누르면 이런 순서로 일어납니다
1. **행 존재 확인** — 테이블이 비어 있으면 팝업 띄우고 종료 (→ 분기 ①)
2. **저장 위치 선택 다이얼로그** — 기본 파일명은 `Attributes_{부재번호}_{날짜시간}.csv`
3. **UTF-8로 파일 쓰기** — 한글 깨짐 없도록 UTF-8 인코딩
4. **헤더 작성** — 첫 줄에 `No,Key,Value`
5. **행 순회** — 테이블의 모든 행(기본 정보부터 형상 정보까지)을 한 줄씩 기록
6. **쉼표 값 이스케이프** — 셀 값에 쉼표가 들어 있으면 큰따옴표로 감쌈 (CSV 오염 방지)
7. **완료 팝업** — "저장되었습니다. 경로: {파일 경로}"

## 🔀 분기 상황
### ① 테이블이 비었을 때
속성 테이블에 아무 행도 없으면(부재를 한 번도 클릭 안 한 상태) 저장 진행 없이 팝업만 띄우고 종료합니다.

### ② 값에 쉼표가 들어 있을 때
| 상태 | 처리 |
|---|---|
| 값에 `,` 포함 | `"값,값"` 형태로 큰따옴표로 감쌈 |
| 쉼표 없음 | 그대로 저장 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "내보낼 속성이 없습니다. 부재를 먼저 선택하세요." | 테이블이 비어 있음 | 3D 뷰어에서 부재를 먼저 클릭하여 속성을 표시시킨 뒤 다시 누르세요 |
| "CSV 저장 오류: {메시지}" | 저장 위치에 권한이 없거나 파일이 열려 있음 | 다른 폴더 선택, 또는 같은 이름의 파일이 엑셀 등에서 열려 있으면 닫고 재시도 |

## 🔗 이어지는 작업
- 부재 속성을 파일로 일괄 되돌리려면 → [CSV 입력](./CSV%20입력.md)
- 다른 부재의 속성도 저장하려면 → [3D 뷰어에서 부재 클릭](./3D%20뷰어에서%20부재%20클릭.md) 후 다시 CSV 출력
