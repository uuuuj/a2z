# UDA 편집

## 🟢 한 줄로
속성 테이블에서 선택한 **부재 속성 한 줄**의 키 또는 값(또는 둘 다)을 수정합니다.

> 💡 "UDA"는 사용자 정의 부재 속성을 뜻합니다. 이 문서에서는 **부재 속성**이라고 부릅니다.

## 📍 버튼 위치
- **탭**: 부재 정보
- **그룹**: 부재 정보 버튼 그룹 (`panelAttributeButtons`)
- **라벨**: [UDA 편집]

## ✅ 누르기 전 확인할 것
- [ ] 3D 뷰어에서 편집할 부재가 선택되어 있는지
- [ ] 속성 테이블에서 **부재 속성 섹션의 행 1개**를 선택(클릭)해 두었는지 (기본 정보/크기/형상 섹션 행은 편집 불가)

## ▶️ 누르면 이런 순서로 일어납니다
1. **부재 선택 확인** — 선택된 부재가 없으면 팝업 띄우고 종료
2. **행 선택 확인** — 테이블에서 행을 고르지 않았으면 팝업 띄우고 종료
3. **부재 속성 행인지 판별** — 선택 행이 부재 속성 섹션이 아니면 (예: 기본 정보 섹션) 팝업 띄우고 종료
4. **기존 값 꺼내기** — 선택 행의 키와 값을 저장해 둠
5. **편집 다이얼로그 표시** — 기존 키/값으로 미리 채워진 창이 뜸
6. **사용자 수정** — 키와 값 둘 다 수정 가능
7. **키 변경 반영** — 키가 바뀌었으면 기존 키를 지우고 새 키로 저장
8. **값 변경 반영** — 값만 바뀌었으면 값만 갱신
9. **둘 다 동일** — 아무 저장 호출 없이 완료 알림만 띄움
10. **테이블 갱신** — 테이블 전체를 다시 그림
11. **완료 팝업** — 편집 성공 알림

## 🔀 분기 상황
### ① 변경 유형에 따른 동작
| 상태 | 처리 |
|---|---|
| 키만 바뀜 | 기존 키 제거 + 새 키로 저장 |
| 값만 바뀜 | 해당 키의 값만 갱신 |
| 키·값 모두 바뀜 | 키 변경 + 값 갱신 |
| 둘 다 그대로 | 저장 없이 알림만 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "부재를 먼저 선택하세요." | 3D 뷰어에서 부재 선택 안 함 | [3D 뷰어에서 부재 클릭](./3D%20뷰어에서%20부재%20클릭.md)으로 부재부터 선택 |
| "편집할 UDA 행을 선택하세요." | 속성 테이블에서 행을 안 고름 | 테이블에서 수정할 행을 클릭해 선택한 뒤 다시 누르세요 |
| "UDA 항목만 편집할 수 있습니다..." | 기본 정보/크기/형상 섹션 행을 골랐음 | 부재 속성(UDA) 섹션 내의 행만 선택 가능합니다. 그 외 섹션은 모델 자체의 읽기 전용 값이라 편집 불가 |
| "UDA 편집 오류: {메시지}" | 저장 중 내부 오류 | 재시도하거나, 다른 부재를 선택했다 다시 돌아와 시도 |
