# ALL 일괄 출력

## 🟢 한 줄로
좌측 **시트 목록의 모든 시트를 자동으로 순회**하며 각각 2D 또는 가공도 도면을 그리고 **전부 `c:\` 루트에 PDF**로 저장합니다.

## 📍 버튼 위치
- **탭**: 도면정보
- **그룹**: 도면 시트 버튼 그룹 (`panelDrawingButtons`)
- **라벨**: [ALL]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지
- [ ] [도면 생성](./도면%20생성.md)으로 **시트 목록에 시트가 1개 이상** 있는지
- [ ] `c:\` 루트에 파일을 저장할 권한이 있는지 (관리자 권한 Windows라면 별도 경로로 쓸 수 없음에 주의)

## ▶️ 누르면 이런 순서로 일어납니다
1. **사전 조건 검증** — 모델 미로드 또는 시트가 0개면 팝업 띄우고 종료
2. **저장 경로 고정** — `c:\` 루트로 고정 (다른 경로 선택 불가)
3. **시트 하나씩 순회** — 시트 목록의 위부터 아래로 차례대로:
   - 그 시트를 **목록에서 자동 선택** (화면도 그 시트 중심으로 전환)
   - 파일명 생성: `{파일베이스}_{시트라벨}_{시간}.pdf`
   - **가공도 시트**(이름이 "가공도_"로 시작)면 가공도 배치 로직으로 그리기
   - 그 외 시트는 일반 2D 시트 도면 그리기
   - 렌더 안정화 대기
   - PDF로 내보내기 (선택 테두리 제거 후)
   - **실패하면 로그만 남기고 계속** (중단하지 않음)
4. **시트마다 메모리 정리** — 2D 캔버스와 중간 데이터를 지우고 강제 메모리 회수 (대량 시트 처리 시 메모리 누적 방지)
5. **완료 팝업** — "전체 N개 중 M개 저장됨\n저장 경로: c:\"

## 🔀 분기 상황
### ① 시트 유형별 렌더
| 시트 이름 | 처리 방식 |
|---|---|
| `가공도_`로 시작 | A4 그리드 레이아웃 배치 로직(가공도 배치) |
| 그 외 | 일반 시트 2D 도면 |

### ② 개별 시트 실패
| 상태 | 처리 |
|---|---|
| 어느 한 시트 PDF 실패 | 로그만 남기고 다음 시트로 계속 (전체 중단 안 함) |
| 시트 데이터가 비어 있음 | 해당 시트 건너뜀 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "먼저 모델을 열어주세요." | 3D 모델 미로드 | [파일 열기](../1.기본-작업/파일%20열기.md)로 로드 |
| "도면 시트가 없습니다. 먼저 '도면 생성'을 해주세요." | 시트 목록이 비어 있음 | [도면 생성](./도면%20생성.md) 먼저 실행 |
| "ALL PDF 출력 중 오류: {메시지}" | 저장 중 치명적 예외 | `c:\` 쓰기 권한 확인, 일부 PDF가 이미 열려 있는지 확인 후 재시도 |
| 완료 팝업에 저장 성공 수가 적음 | 일부 시트가 저장 실패 | `c:\`에 같은 이름 파일이 열려 있었거나 공간 부족. 관련 파일 정리 후 재시도 |

## 🔗 이어지는 작업
- `c:\` 폴더를 열어 저장된 PDF 확인
- 실패한 시트만 개별 저장하려면 → 해당 시트 선택 → [2D 출력](./2D%20출력.md) → [PDF 출력](./PDF%20출력.md)
- 가공도 시트들만 한 장에 몰아 출력하려면 → [가공도 일괄 출력](./가공도%20일괄%20출력.md)
