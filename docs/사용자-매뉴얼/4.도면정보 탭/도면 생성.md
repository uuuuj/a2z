# 도면 생성

## 🟢 한 줄로
Clash 결과(서로 맞닿아 간섭하는 부재 정보)를 바탕으로 **연결된 부재끼리 묶어 여러 장의 도면 시트로 자동 분할**합니다.

## 📍 버튼 위치
- **탭**: 도면정보
- **그룹**: 도면 시트 버튼 그룹 (`panelDrawingButtons`)
- **라벨**: [도면 생성]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지 ([파일 열기](../1.기본-작업/파일%20열기.md))
- [ ] **BOM 목록이 수집**되어 있는지 ([BOM](../2.작업-데이터%20탭/BOM.md) 먼저 실행)
- [ ] **Clash 검사가 완료**되어 있는지 ([Clash](../2.작업-데이터%20탭/Clash.md) 먼저 실행)

## ▶️ 누르면 이런 순서로 일어납니다
1. **사전 조건 검증** — 모델·BOM·Clash 중 하나라도 준비 안 되면 팝업 띄우고 종료 (→ 에러)
2. **1번 시트 생성** — 전체 BOM 부재가 한 장에 담긴 "전체 설치도" 시트
3. **부재 간 인접 관계 구축** — Clash 결과를 바탕으로 "어떤 부재가 어떤 부재와 연결되어 있는지" 맵을 만듭니다
4. **부재별로 순회** — BOM의 모든 부재를 하나씩 꺼내며:
   - 이미 다른 시트에 포함된 부재면 **건너뜀** (중복 방지)
   - 아직 미포함이면 그 부재를 중심으로 **연결된 부재를 모두 묶어** 새 시트 생성
5. **마지막 시트** — 모든 부재가 보이는 **전체 설치도 시트** 추가
6. **도면 시트 목록 갱신** — 좌측 시트 목록(`lvDrawingSheet`)에 `시트 번호 / 대표 부재 / 부재 수`가 순서대로 표시
7. **완료 팝업** — "도면 시트 {N}개가 생성되었습니다."

> 💡 참고: [Clash](../2.작업-데이터%20탭/Clash.md) 검사 완료 직후에 **자동으로 한 번** 호출되기도 합니다. 이 경우는 사전 조건 검사·완료 팝업을 생략하고 조용히 갱신만 합니다.

## 🔀 분기 상황
### ① 호출 경로
| 호출자 | 동작 |
|---|---|
| 사용자가 직접 [도면 생성] 클릭 | 사전 조건 검사 + 완료 팝업 |
| [Clash](../2.작업-데이터%20탭/Clash.md) 검사 끝나면 자동 호출 | 검사·팝업 생략, 목록만 갱신 |

### ② 부재 묶음 중복 제거
| 상태 | 처리 |
|---|---|
| 이미 다른 시트에 포함된 부재 | 새 시트 만들지 않고 건너뜀 |
| 신규 부재 | 새 시트 생성 + 인접 부재까지 묶기 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "먼저 모델을 열어주세요." | 3D 모델이 로드되지 않음 | [파일 열기](../1.기본-작업/파일%20열기.md)로 먼저 모델 로드 |
| "BOM 데이터가 없습니다." | BOM 수집 건너뜀 | [BOM](../2.작업-데이터%20탭/BOM.md) 버튼으로 먼저 수집 |
| "Clash 데이터가 없습니다. 먼저 Clash 검사를 수행..." | 간섭 검사 안 됨 | [Clash](../2.작업-데이터%20탭/Clash.md) 버튼으로 먼저 검사 실행 |

## 🔗 이어지는 작업
- 특정 시트를 선택하면 → 3D 뷰어가 그 시트의 부재 중심으로 자동 전환 ([시트 선택 시 화면 전환](../5.목록%20조작/시트%20선택%20시%20화면%20전환.md))
- 선택 시트의 2D 도면을 뽑으려면 → [2D 출력](./2D%20출력.md)
- 선택 시트 BOM 정보를 재집계하려면 → [BOM 수집](./BOM%20수집.md)
- 가공도 시트만 한 장에 배치 출력하려면 → [가공도 일괄 출력](./가공도%20일괄%20출력.md)
