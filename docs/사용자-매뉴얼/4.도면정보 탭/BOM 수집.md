# BOM 수집

## 🟢 한 줄로
도면정보 탭 우측의 **BOM 정보 표**를, 현재 선택된 시트(없으면 전체) 부재 기준으로 다시 집계합니다.

> 💡 이 버튼은 [작업/데이터 탭의 BOM](../2.작업-데이터%20탭/BOM.md) 버튼과 **다릅니다**. 이 버튼은 "도면정보 탭 전용 BOM 표"에 대해 **시트별로 필터해서** 다시 그려주는 용도입니다.

## 📍 버튼 위치
- **탭**: 도면정보
- **그룹**: BOM 정보 헤더 (`panelDrawingBOMHeader`, 우측 패널 상단)
- **라벨**: [BOM 수집]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지
- [ ] (선택) 좌측 시트 목록에서 특정 시트를 골라 두었으면 **그 시트 부재만** 대상으로 집계됩니다. 고르지 않으면 전체 모델 대상

## ▶️ 누르면 이런 순서로 일어납니다
1. **BOM 정보 표 초기화** — 우측의 BOM 정보 표(`lvDrawingBOMInfo`)를 비웁니다
2. **부재 노드 확보** — 모델에서 Part(부품) 단위 부재 목록을 읽어 옴. Part가 없으면 Body 단위로 대체
3. **시트 필터 판단** — 좌측 시트 목록에서 선택된 시트가 있으면 **그 시트에 속한 부재만** 대상 (→ 분기 ①)
4. **부재 속성 조회** — 각 부재의 규격(Item·Size), 재질(Material), 중량(Weight) 정보를 읽습니다
5. **동일 규격 합산** — Item + Size + Material이 같은 부재들은 한 행으로 묶어 **개수·총중량** 집계
6. **표에 행 추가** — 그룹별로 한 줄씩 표시
7. **완료** — 팝업 없이 표가 갱신됨

## 🔀 분기 상황
### ① 집계 대상 범위
| 상태 | 대상 |
|---|---|
| 좌측 시트 목록에서 시트 선택됨 | **그 시트의 부재만** |
| 시트 선택 없음 | 모델 전체의 모든 부품 |

### ② Part / Body 대체
| 상태 | 처리 |
|---|---|
| Part 단위 부재 있음 | Part 단위에서 속성 읽음 |
| Part 없음 | Body 단위로 자동 대체 |

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "로드된 모델이 없거나 노드를 찾을 수 없습니다." | 모델 미로드 또는 부재가 하나도 없음 | [파일 열기](../1.기본-작업/파일%20열기.md)로 모델 로드 후 재시도 |
| "BOM 정보 수집 오류: {메시지}" | 내부 처리 예외 | 다시 시도. 문제 반복되면 모델을 다시 열어보세요 |

## 🔗 이어지는 작업
- 방금 표시된 부재로 2D 도면을 그리려면 → [2D 출력](./2D%20출력.md)
