# 2D 출력

## 🟢 한 줄로
**좌측에서 선택한 도면 시트**의 부재들만 모아 은선(점선) 처리된 2D 도면을 한 장 그립니다.

> 💡 이 버튼은 [작업/데이터 탭의 2D 생성](../2.작업-데이터%20탭/2D%20생성.md)과 **다릅니다**. 작업/데이터 탭의 "2D 생성"은 **전체 BOM 부재**로 도면을 그리지만, 여기서는 **지금 선택한 시트의 부재만** 도면으로 만듭니다.

## 📍 버튼 위치
- **탭**: 도면정보
- **그룹**: 도면 시트 버튼 그룹 (`panelDrawingButtons`)
- **라벨**: [2D 출력]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지
- [ ] [치수 추출](../1.기본-작업/치수%20추출.md)을 완료해 **도면 시트 목록에 시트가 1개 이상** 자동 생성됐는지
- [ ] 좌측 **시트 목록에서 시트 한 개를 선택**해 두었는지
- [ ] 선택 시트에 포함된 부재가 최소 1개 이상인지

## ▶️ 누르면 이런 순서로 일어납니다
1. **모델 확인** — 열려 있지 않으면 팝업 띄우고 종료
2. **시트 선택 확인** — 선택된 시트가 없으면 팝업 띄우고 종료
3. **시트 데이터 확보** — 선택 시트의 부재 목록을 꺼냅니다. 비어 있으면 팝업 띄우고 종료
4. **해당 시트 부재만 표시** — 그 시트에 속한 부재만 보이게, 나머지는 숨김
5. **은선(점선) 모드로 전환** — 가려진 모서리가 점선으로 표시됩니다
6. **번호 풍선 생성** — 각 부재에 부품 번호가 적힌 풍선을 배치, 겹치면 자동 위치 조정
7. **지시선 추가** — 풍선과 해당 부재를 잇는 보조선 생성
8. **우측 BOM 표 재집계** — 이 시트 부재 기준으로 BOM 정보 표 갱신
9. **2D 영역 표시** — 화면 오른쪽에 2D 도면 캔버스가 등장 (3D+2D 분할)
10. **완료** — 캔버스에 도면 확인 가능

## 🔀 분기 상황
### ① 풍선 위치 충돌
| 상태 | 처리 |
|---|---|
| 다른 풍선과 겹침 | 자동으로 오프셋 적용해 이동 후 재배치 |
| 겹침 없음 | 기본 위치 사용 |

### ② BOM 표 재집계
이 버튼은 내부적으로 선택 시트 부재 기준으로 [BOM 수집](./BOM%20수집.md) 로직을 **자동 실행**합니다. 별도로 BOM 수집 버튼을 또 누를 필요 없습니다.

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "먼저 모델을 열어주세요." | 3D 모델 미로드 | [파일 열기](../1.기본-작업/파일%20열기.md)로 먼저 로드 |
| "도면 시트를 선택해주세요." | 좌측 시트 목록에서 시트 미선택 | 시트 한 개를 클릭 선택 후 다시 누르세요 |
| "유효한 시트 데이터가 없습니다." | 선택 시트에 부재가 없거나 데이터 깨짐 | [치수 추출](../1.기본-작업/치수%20추출.md)을 다시 실행해 시트를 재생성 |
