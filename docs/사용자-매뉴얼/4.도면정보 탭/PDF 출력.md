# PDF 출력

## 🟢 한 줄로
도면정보 탭에서 **지금 그려 놓은 시트 2D 도면**을 벡터 PDF 파일로 저장합니다.

> 💡 이 버튼은 [작업/데이터 탭의 PDF 내보내기](../2.작업-데이터%20탭/PDF%20내보내기.md)와 **다릅니다**. 여기서 저장하는 건 **선택 시트 기준으로 그린 도면**이며, 파일명도 기본값이 `Sheet2D_...` 형태입니다.

## 📍 버튼 위치
- **탭**: 도면정보
- **그룹**: 도면 시트 버튼 그룹 (`panelDrawingButtons`)
- **라벨**: [PDF 출력]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지
- [ ] [2D 출력](./2D%20출력.md)으로 **도면 2D가 먼저 생성**되어 화면 오른쪽에 보이는지

## ▶️ 누르면 이런 순서로 일어납니다
1. **모델 확인** — 미로드면 팝업 띄우고 종료
2. **2D 생성 여부 확인** — 2D 도면이 없으면 팝업 띄우고 종료
3. **저장 위치 다이얼로그** — 기본 파일명 `Sheet2D_{날짜시간}.pdf`
4. **선택 테두리 제거** — 저장되는 도면에 선택 박스가 남지 않도록 선택 해제
5. **벡터 PDF 저장** — 현재 2D 뷰를 벡터 PDF로 내보냅니다
6. **완료 팝업** — 저장 경로 안내

## 🔀 분기 상황
없음. 저장 다이얼로그에서 취소를 눌러도 조용히 종료됩니다.

## ⚠️ 에러 메시지와 대처
| 팝업 문구 | 왜 뜨나요? | 어떻게 해결하나요? |
|---|---|---|
| "먼저 모델을 열어주세요." | 모델 미로드 | [파일 열기](../1.기본-작업/파일%20열기.md)로 먼저 로드 |
| "먼저 '2D 출력' 버튼으로 2D 도면을 생성해주세요." | 2D 도면을 아직 안 그림 | [2D 출력](./2D%20출력.md) 먼저 실행 |
| "PDF 저장 중 오류: {메시지}" | 경로에 권한이 없거나 같은 이름 파일이 열려 있음 | 다른 폴더 선택, 또는 해당 PDF가 뷰어에서 열려 있으면 닫고 재시도 |

## 🔗 이어지는 작업
- 다른 시트도 저장하려면 → 시트 선택 → [2D 출력](./2D%20출력.md) → [PDF 출력](./PDF%20출력.md) 반복
- 모든 시트를 자동으로 한번에 저장하려면 → [ALL 일괄 출력](./ALL%20일괄%20출력.md)
