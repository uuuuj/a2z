# 가공도 일괄 출력

## 🟢 한 줄로
시트 목록 중 이름이 **"가공도_"로 시작하는 모든 시트**를 수집해, **A4 한 장에 최대 18개(8×3 배치)** 로 한꺼번에 뽑습니다.

> 💡 [작업/데이터 탭의 가공도 출력](../2.작업-데이터%20탭/가공도%20출력.md)은 **선택한 한 개 부재**를 출력하지만, 이 버튼은 **이미 만들어진 가공도 시트들을 모두 모아** 한 장의 A4에 배치합니다.

## 📍 버튼 위치
- **탭**: 도면정보
- **그룹**: 도면 시트 버튼 그룹 (`panelDrawingButtons`)
- **라벨**: [가공도 출력]

## ✅ 누르기 전 확인할 것
- [ ] 3D 모델이 열려 있는지
- [ ] 시트 목록에 **"가공도_"로 시작하는 시트가 1개 이상** 있는지 ([작업/데이터 탭 가공도 출력](../2.작업-데이터%20탭/가공도%20출력.md)을 여러 번 수행해 시트를 미리 만들어 두어야 합니다)

## ▶️ 누르면 이런 순서로 일어납니다
1. **가공도 시트 필터링** — 시트 목록에서 라벨이 "가공도"로 시작하고 부재가 있는 시트만 골라냅니다
2. **개수 검사** — 한 건도 없으면 팝업 띄우고 종료
3. **애니메이션 끄기** — 렌더 일관성을 위해 뷰 애니메이션 잠시 비활성
4. **3D 주석·측정 지우기** — 기존에 남은 주석·치수 등을 정리
5. **2D 캔버스 완전 초기화** — 깨끗한 상태에서 시작
6. **화면 분할 조정** — 좌측 2D 영역 폭을 20% 정도로
7. **A4 캔버스 세팅** — 가로 297mm × 세로 210mm
8. **테두리·그리드 생성** — 외곽 테두리와 내부 **8×6 배치 그리드**
9. **도면정보 표 삽입** — 우하단 기준(앵커) 5×4 표
10. **선 두께 설정** — 모델 선 굵기 2.0 / 치수 선 0.3 / 글자 두께 5
11. **셀에 시트 배치** — 열 우선 순서로 최대 **18개**까지 셀에 꽂음 (넘으면 앞에서부터 18개만)
12. **완료** — 2D 캔버스에 가공도 일괄 배치 결과 표시. 이후 필요하면 별도로 [PDF 출력](./PDF%20출력.md)으로 저장

## 🔀 분기 상황
### ① 가공도 시트 수량
| 상태 | 처리 |
|---|---|
| 18개 초과 | 앞에서부터 18개만 배치 (나머지는 생략) |
| 1~18개 | 모두 배치 |
| 0개 | 팝업 띄우고 종료 |

### ② 배치 순서
총 18개 슬롯 = **라벨 칼럼(1·3·5열) + 모델 칼럼(2·4·6열)** 쌍을 3그룹 × 6행 형태로 사용합니다. 열을 먼저 채우고 다음 열로 넘어갑니다.

## ⚠️ 에러 메시지와 대처
