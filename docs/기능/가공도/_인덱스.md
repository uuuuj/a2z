# MfgDrawing 기능

`Form1.MfgDrawing.cs` 소속. 단일 부재 가공도 및 전체 배치 가공도 생성 기능입니다.

## 기능 목록
| ID | 기능 | 트리거 | 유형 | 문서 |
|---|---|---|---|---|
| MFG-001 | 선택 부재 가공도 생성 | btnMfgDrawing_Click | User Action | [mfg-drawing](./가공도%20단일.md) |
| MFG-002 | 전체 부재 배치 가공도 | btnMfgDrawingSheet_Click | User Action | [mfg-drawing-sheet](./가공도%20시트.md) |

## 공통 처리 특성
- SPREF UDA 기반 PAD/PLATE 판별
- 최장축/최단축 방향 결정
- ORIENTATION UDA 기반 카메라 회전 (있는 경우)
- Osnap 수집 → 치수 자동 생성
- Hidden Line + 풍선 + 보조선 적용
