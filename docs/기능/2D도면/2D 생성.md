# 전체 BOM 2D 도면 생성

## 1. 개요
현재 `bomList`의 모든 부재를 임시 `DrawingSheetData`로 묶어 `GenerateSheetDrawing2D()`에 위임한다. Hidden Line 렌더·풍선·보조선·벡터 PDF 대응 도면이 결과로 나온다.

## 2. 트리거
| 항목 | 값 |
|---|---|
| 유형 | User Action |
| 입력 | `btnGenerate2D` 버튼 클릭 |
| 위치 | 메인 폼 > Drawing2D 탭 |

## 3. 사전 조건
- [ ] 3D 모델 로드됨
- [ ] `bomList.Count > 0`

## 4. 전체 동작 흐름 (Happy Path)

| # | 단계 | 주체 | 설명 |
|---|---|---|---|
| 1 | 모델 로드 확인 | Form1 | `IsOpen()` → [E01] |
| 2 | BOM 확인 | Form1 | `bomList.Count == 0` → [E02] |
| 3 | 임시 시트 생성 | Form1 | `DrawingSheetData` SheetNumber=1 |
| 4 | Base 이름 설정 | Form1 | [분기 A] |
| 5 | 모든 BOM Index 주입 | Form1 | `sheet.MemberIndices.Add(bom.Index)` |
| 6 | 2D 생성 위임 | Form1 | `GenerateSheetDrawing2D(sheet)` 호출 |

> 구현 상세는 [코드 레퍼런스](../../code-reference/form1-drawing2d.md#btnGenerate2D_Click) 참고

## 5. 주요 분기 처리

### [분기 A] Base 이름 결정
| 조건 | 처리 |
|---|---|
| `selectedAttributeNodeIndex != -1` | 선택 노드의 NodeName (없으면 파일명) |
| 선택 없음 + 파일 경로 있음 | `Path.GetFileNameWithoutExtension(currentFilePath)` |
| 선택 없음 + 파일 경로 없음 | "전체" |

### [분기 B] GenerateSheetDrawing2D 내부 분기
위임 함수 내부 상세는 [시트별 2D 생성](../도면시트/시트%202D%20렌더.md)의 §5 참고 (동일 함수 사용).

## 6. 예외 / 에러 처리

| ID | 조건 | 동작 | 사용자 피드백 | 결과 상태 |
|---|---|---|---|---|
| E01 | 모델 미로드 | return | MessageBox "먼저 모델을 열어주세요." | 상태 변화 없음 |
| E02 | `bomList.Count == 0` | return | MessageBox "BOM 데이터가 없습니다. 먼저 BOM을 수집..." | 상태 변화 없음 |
| E99 | `GenerateSheetDrawing2D` 내부 예외 | 상위 함수 catch | — | 부분 렌더링 가능 |

## 7. 상태 변화 (Before / After)

| 대상 | Before | After |
|---|---|---|
| `vizcore3d.ViewMode` | 3D 또는 이전 | `Both` (2D + 3D 동시 표시) |
| `vizcore3d.View.RenderMode` | SOLID | DASH_LINE (Hidden Line) |
| `balloonOverrides` | 이전 | 현재 시트 기준 갱신 |
| 2D 캔버스 | 빈 또는 이전 | 풍선·보조선 포함 도면 |
| 임시 `DrawingSheetData` | 없음 | 메서드 내 로컬 객체 (저장 안됨) |
