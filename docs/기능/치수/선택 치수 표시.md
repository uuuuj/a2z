# 선택 치수 3D 표시

## 1. 개요
`lvDimension`에서 선택된 체인 치수들을 3D 뷰어에 **축별 오프셋을 적용**하여 겹치지 않게 표시한다. 측정 스타일(정수 표시, 파란색, FontSize14, Bold)을 명시적으로 설정한다.

## 2. 트리거
| 항목 | 값 |
|---|---|
| 유형 | User Action |
| 입력 | `btnDimensionShowSelected` 버튼 클릭 |
| 위치 | 메인 폼 > 치수 탭 |

## 3. 사전 조건
- [ ] `chainDimensionList` 채워짐 ([BOM-004](../BOM/메인%20치수%20추출.md))
- [ ] `lvDimension`에서 1개 이상 선택

## 4. 전체 동작 흐름 (Happy Path)

| # | 단계 | 주체 | 설명 |
|---|---|---|---|
| 1 | 선택 확인 | Form1 | `SelectedItems.Count == 0` → [E01] |
| 2 | BeginUpdate | SDK | 화면 갱신 일시 중지 |
| 3 | 기존 결과 심볼 제거 | SDK | `Clash.ClearResultSymbol()` (Measure는 유지) |
| 4 | 측정 스타일 설정 | SDK | Prefix/Unit 제거, NumberOfDecimalPlaces=0, 파란색, FontSize14, Bold |
| 5 | 축별 오프셋 카운터 초기화 | Form1 | X/Y/Z Dict, `offsetStep = 50.0f` |
| 6 | 선택 치수 순회 | Form1 | 축별 오프셋 누적 적용 |
| 7 | 축별 Vertex 생성 | Form1 | X축 → Y 오프셋 / Y·Z축 → X 오프셋 [분기 A] |
| 8 | 치수 추가 | SDK | `Review.Measure.AddCustomAxisDistance(axis, start, end)` |
| 9 | 피벗 설정 | SDK | 첫 번째 치수 중심을 `SetPivotPosition` |
| 10 | EndUpdate | SDK | 화면 갱신 재개 |
| 11 | 완료 알림 | UI | MessageBox "{N}개의 치수가 표시되었습니다." |

> 구현 상세는 [코드 레퍼런스](../../code-reference/form1-dimensions.md#btnDimensionShowSelected_Click) 참고

## 5. 주요 분기 처리

### [분기 A] 축별 오프셋 방향
| Axis | 오프셋 적용 방향 |
|---|---|
| X | Y 방향으로 -currentOffset |
| Y | X 방향으로 -currentOffset |
| Z | X 방향으로 -currentOffset |

## 6. 예외 / 에러 처리

| ID | 조건 | 동작 | 사용자 피드백 | 결과 상태 |
|---|---|---|---|---|
| E01 | 선택 없음 | return | MessageBox "치수를 선택해주세요." | 변화 없음 |
| E02 | 처리 중 예외 | catch | MessageBox "치수 표시 중 오류: {msg}" | 일부 치수만 표시 가능 |
