# Dimensions 기능

`Form1.Dimensions.cs` 소속. 체인 치수 표시/삭제/필터링 UI 흐름입니다.

## 기능 목록
| ID | 기능 | 트리거 | 유형 | 문서 |
|---|---|---|---|---|
| DIM-001 | 선택 치수 3D 표시 | btnDimensionShowSelected_Click | User Action | [show-selected](./선택%20치수%20표시.md) |
| DIM-002 | 치수 삭제 | btnDimensionDelete_Click | User Action | [delete](./치수%20삭제.md) |
| DIM-003 | X축 뷰 + 치수 표시 | btnShowAxisX_Click | User Action | [show-axis-x](./X축%20치수%20표시.md) |
| DIM-004 | Y축 뷰 + 치수 표시 | btnShowAxisY_Click | User Action | [show-axis-y](./Y축%20치수%20표시.md) |
| DIM-005 | Z축 뷰 + 치수 표시 | btnShowAxisZ_Click | User Action | [show-axis-z](./Z축%20치수%20표시.md) |
| DIM-006 | ISO 뷰 + 치수 표시 | btnShowISO_Click | User Action | [show-iso](./ISO%20풍선%20표시.md) |
| DIM-007 | 풍선 위치 수동 조정 | btnBalloonAdjust_Click | User Action | [balloon-adjust](./풍선%20위치%20조정.md) |
| DIM-008 | Clash 선택 시 치수 필터 | LvClash_SelectedIndexChanged | Event Callback | [lvclash-selected](./Clash%20선택%20시%20치수%20필터.md) |
| DIM-009 | 현재 뷰 기반 체인 치수 추출 | btnExtractDimension_Click | User Action | [extract-dimension](./현재%20뷰%20기반%20체인%20치수%20추출.md) |
| DIM-010 | 설치도 연결 영역 Osnap 치수 | 도면 시트 자동 생성 | Internal Action | [installation-dimension](./설치도%20치수%20추출.md) |
