# 2026-06-30 — 가공도 EA 부재 가로 배치 + 치수/풍선 정리

## 주제
가공도에서 EA(앵글) 부재를 **가로로 눕혀** 1·2번 뷰로 출력하고, 각 뷰의 치수(가로 길이·세로 높이)·선 굵기·풍선을 제작도 수준으로 맞추는 작업. 여러 세션에 걸친 대형 작업의 핵심 구간.

## 배경
EA 부재가 출력에서 **세로로 박히고**, 치수가 어긋나고, 선 굵기가 균일하고, 높이가 누락되는 문제. 사용자가 사내 PC에서 실기 출력하며 이미지·로그로 피드백, Claude가 수정→commit→push 반복(검증 사이클).

## 확정된 핵심 지식 ⭐ (다음 세션 필수)

### 1. 뷰 번호 매핑 (로그로 확정)
- **사용자 "1번 뷰" = 코드의 `secondary`(BuildEaSecondaryScene)** — 가로(길이)+세로(높이) 둘 다 그림
- **사용자 "2번 뷰" = 코드의 `primary`(BuildMfgSceneCore)** — 세로만 (길이는 reserve로 skip)
- 즉 구조는 이미 스펙과 일치: 1번=가로+세로, 2번=세로만. **재구성 불필요**

### 2. 캡처 방향 메커니즘 (실기 확정)
- 2D 캡처(`Create2DViewObjectWithModelHiddenLineAtCanvasOrigin`)는 **뷰 방향별 고정 투영 + 화면축 회전**만 반영. **카메라 ±방향·up-vector·`SetCameraPosAndDirection`는 무시됨** (그래서 up-vector 방식 실패)
- 가로/세로 판정은 **GetCameraAxis 추측 금지** → **임시 캡처 objW/objH(ground truth)** 로만
- 회전은 `RotateCameraByScreenAxis(0,0,90)` (캡처 반영됨), 캡처 후 -90 원복 필수(누적 차단)
- 회전 발생 조건 = **LongestAxis=="Z"** (X/Y 최장은 카메라 방향만으로 가로)

### 3. 회전 화면 매핑 (calibration 확정)
- view=X(2차, 회전): 화면-위 = `-Y`(false), 화면-오른쪽 = `+Z`
- view=Z(2차, 비회전): 화면-위 = `-X`, 화면-오른쪽 = `-Y`
- view=Y(1차): 화면-오른쪽 = `-X`(비회전) / `+Z`(회전)
- **주의: balloon table(bHAxis/bVAxis)의 view=Z H/V는 실제와 어긋남**(H=Y가 실제) — 신뢰 금지

### 4. 죽은/무효 메커니즘 (재시도 금지)
- `AlignDistanceTextPosition` — 효과 없음 (텍스트 위치는 `SetMeasureItemDistanceTextPos`로만)
- `SetCameraPosAndDirection` up-vector — 캡처 미반영
- 카메라 X_PLUS/X_MINUS — 캡처 미반영
