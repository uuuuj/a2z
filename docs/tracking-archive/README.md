## 왜 원본을 남겼나

이슈는 GitHub 서버에만 있고 `git clone`에 담기지 않습니다. `issues.json`이 그 공백을 메우지만, 이관 과정의 판단 근거(어느 항목이 어느 이슈로 갔는지, 왜 그렇게 묶었는지)는 원본을 봐야 확인됩니다. 감사 추적용으로 보관합니다.

특히 Excel 스냅샷은 **`완료 확인일` 기준의 시점 분석**(출장 전후 성과 등)을 재현할 수 있는 유일한 자료입니다. 모든 이슈가 2026-07-21 이후에 생성돼 GitHub만으로는 그 이전 시점을 알 수 없습니다.
