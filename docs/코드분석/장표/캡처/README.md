# 장표에 넣을 캡처

이 폴더에 PNG를 넣으면 덱에 base64로 박아 넣는다 (단일 HTML 유지).

| 파일명 | 무엇을 찍나 | 들어갈 장 |
|---|---|---|
| `폴더구조.png` | 솔루션 탐색기 — A2Z 프로젝트 트리 펼친 상태 | 파일 구조 |
| `파일구조.png` | Form1.*.cs 13개 파일이 보이는 목록 | 파일 구조 |
| `메서드.png` | 주석(///)이 달린 메서드 하나 — VS 편집기 화면 | 남은 것 |

- 확대 배율 100~125%, 배경 흰 테마 권장 (덱이 흰 바탕)
- 사내 정보(서버 주소·계정·도면 실명)가 보이면 그 부분은 가리고 캡처
