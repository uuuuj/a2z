## 4. 층으로 보면

강제된 경계는 없지만 역할은 갈려 있습니다.

```
조립자층   남을 많이 부르는 파일          ← 버튼 뒤
중간층     부르기도 불리기도 하는 파일     ← 그리기·계산
기반층     남이 많이 부르는 파일          ← 공용 상태·부품
```

**"모듈화가 안 됐다"가 아니라 "층은 이미 있는데 컴파일러가 강제하지 않는다"** 입니다.
리팩토링은 없는 구조를 새로 짜는 게 아니라 **이미 있는 층을 진짜 클래스로 굳히는 일**입니다.
