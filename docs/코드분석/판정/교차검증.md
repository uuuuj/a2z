# 교차검증

문서를 쓴 쪽이 아닌 쪽이 읽고 근거를 댄 것을 모은다.

> 🔴 **지적하는 쪽은 근거만 댄다. 판정은 그 문서의 담당자가 내린다.**
> 상대 문서를 직접 고치지 않는다 — "한 파일은 한 도구만" 규칙을 지키기 위해서다.

## 무엇을 보나

1~4절은 [`verify.py`](../verify.py)가 기계로 잡는다. **5절과 6절만** 본다.

| 볼 것 | 어떻게 |
|---|---|
| **5절 알고리즘** | 수식·임계값이 코드와 맞나. 숫자는 `grep`으로 바로 확인된다 |
| **6절 ② 떼어낼 수 있다** | 정말 그런가. **놓친 공유 상태 참조가 없나** → [`자동생성/파일 구조.md`](../자동생성/파일%20구조.md) 2절과 대조 |
| **6절 ③ 못 뗀다** | 정말 못 떼나. 주입·반환값으로 풀리는 걸 구조적 한계로 적지 않았나 |
| **2절 플로우차트** | 빠진 갈래가 있나 — 특히 **예외·취소·조기 return** |

**전수 재독은 하지 않는다.** 문서를 읽고 의심 가는 곳만 코드로 확인한다.
