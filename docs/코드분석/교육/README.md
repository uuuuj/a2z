# 교육 — 실행 순서로 코드 읽기

> **목적**: 발표자(허영인)가 **코드를 직접 보면서** 구조와 기능을 이해한다.
> 어떤 코드가 어떤 기능에 쓰이고, 어떤 API를 부르고, 어떤 함수로 이어지고, 어떤 파라미터가 오가는지.
> 착수 2026-08-23. **본 것도 안 본 것도 전부 여기 남긴다.**

## 왜 실행 순서인가

파일별 문서 13개는 **파일 단위**라 "이 파일이 뭘 하나"는 알아도 **"프로그램이 어떻게 흘러가나"** 는 안 보인다.
그래서 교육은 **프로그램이 켜지는 첫 줄부터** 도면 PDF가 나올 때까지 순서대로 간다.

## 읽는 법

- 🔑 표시 = **이 교시에서 꼭 이해해야 하는 것**
- 🔴 표시 = 조사 중 나온 **결함**. 코드에서 눈으로 확인되는 것
- 📌 표시 = **왜 이렇게 짰나** / 리팩토링과 이어지는 지점
- 각 교시 끝의 「직접 해볼 것」은 VS에서 5분이면 확인되는 것만 담았다
