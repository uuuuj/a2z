# 9. `Form1.ExcelTemplate.cs` — 101줄 · 4개 · 기반

**표제부 REV 이력 표 채우기.** 프로젝트 최소 파일인데 **주석이 절반.**

🔑 **`KeepBorder` 4줄이 SDK 우회**:
```csharp
return string.IsNullOrWhiteSpace(value) ? " " : value.Trim();
```
빈 값(`""`)이면 `{Input}`이 남아 괘선이 지워지고, 공백 1칸(`" "`)이면 치환되어 **괘선이 산다.**
SDK에 「괘선 켜라/꺼라」 API가 없어 **값 유무로 간접 제어**한다.
반대로 미사용 행은 키를 아예 안 넣어 괘선을 지운다 — **같은 원리를 양방향으로.**

📌 슬롯이 거꾸로: `{194, 188, 182, 176, 170}` — 리비전이 **아래에서 위로 쌓인다.**
📌 REV는 항상 0, 작성자·검도자·승인자는 **입력 수단 미정이라 빈칸**(#64).
📌 **폐기 기록 3건**이 주석에: JSON 사전변환(290초) · View 좌표 캐시(staleness) · 6만 셀 템플릿(크래시).
→ *"템플릿을 시트마다 읽는데 캐시 안 붙였다"* 는 **붙였다가 뺀 것.**
