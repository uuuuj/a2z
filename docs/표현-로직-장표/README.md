# 표현 로직 장표

도면에 그려지는 각 요소(**보조선 · 시작 갭 · 오프셋 · 각도 · 치수 텍스트 · 풍선** 등)가
**어떤 로직·기준으로 그 위치·크기·방향으로 표현되는지**를,
사람이 한눈에 보도록 **가로 슬라이드(HTML) 한 장**으로 정리해 모아두는 폴더.

## 왜 별도 폴더인가
- `docs/기술 노트/`는 **텍스트 사양**(정본 기준값) — 정밀하지만 한눈에 안 들어온다.
- 이 폴더는 그 사양을 **발표용 장표**로 시각화 — 담당자·팀원이 빠르게 이해하는 용도.
- 하나의 요소 = 하나의 HTML = 하나의 슬라이드(16:9). 브라우저로 바로 열거나 PDF로 뽑는다.

## 작성 규칙
- **하나의 요소 = 하나의 HTML.** 내용이 많으면 여러 슬라이드로 나누되(세로 스크롤·스냅), **각 슬라이드는 16:9 한 장**으로 한눈에 들어오게.
- 수치는 **코드 `const` 선언부 기준**으로 적는다 — 사양 문서·주석은 옛 값(stale)일 수 있음.
- 슬라이드에 **기준일**을 명기한다(수치는 시점에 따라 바뀜).
- 제작도 / 가공도처럼 경로가 다르면 **표로 나란히** 비교한다.
- 값의 최종 출처(파일·라인)를 장표 안에 남겨, 나중에 검증 가능하게 한다.
