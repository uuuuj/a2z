## 2. 이 지시가 뜻하는 것

과제가 **"만들기"에서 "판정하기"로** 바뀌었다.

| | 이전 | 지금 |
|---|---|---|
| 목표 | 기능 완성 → 사외조달 검증 | **복잡형상 가능 여부 판정** |
| 산출물 | 도면 3종 · 최종 PDF | **된다/안 된다 + 필요 API 목록** |
| 다음 결정 | 개발 일정 | **코어에 돈을 태울 것인가** |

팀장이 원하는 것은 진척 보고가 아니라 **의사결정 재료**다.
"몇 개월 끌려다녔다"는 말이 배경이므로, **소프트힐스 의존을 끝낼 판단**을 하려는 자리다.
