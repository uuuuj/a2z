# 가공도 엑셀 템플릿 + 페이지 레이아웃 재설계 (Step C-Mfg)

## 0. 배경

Step B (가공도 통합) 결과 사용자 검증 — **실사용 사양과 큰 차이 발견**:

- 부재 너무 크게 나옴 + 풍선도 너무 김 + 보조선 규칙 없음
- 자동 4분면 풍선 알고리즘은 가공도 본질과 무관
- 가공도 본질 = **5행/페이지 + 행별 BOM이름:모델 = 1:3 비율 + 부재 가공 정보 (전체 치수 + 홀·슬롯)**
- 제작도와 같은 엑셀 템플릿 패턴 필요
- EA 부재는 "위에서 + 꺾인 방향" 두 뷰 (T-064 EA 비활성화 사양 폐기, isEA 재활성)
- Osnap 홀 둘레 포인트 다수 → 체인 치수 폭증

→ Step B 결과 일부 재사용 + 새 구조 추가. **B 작업 16 commit 유지**, 새 가공도 함수 추가 + 기존 어댑터 재배선.

## 3. 가공도 엑셀 템플릿 설계

### 3.1 페이지 레이아웃 (A4 가로 297×210mm)

```
┌─────────────────────────────────────────────────────────┐ A4 297×210
│ ┌───────────────────────────────┐ ┌─────────────────┐ │
│ │ {Name_1}│ {View_1}            │ │ {도면정보}      │ │
│ ├───────────────────────────────┤ │ - 프로젝트     │ │
│ │ {Name_2}│ {View_2}            │ │ - 선박번호      │ │
│ ├───────────────────────────────┤ │ - 도면종류      │ │
│ │ {Name_3}│ {View_3}            │ │ - 페이지 N/M    │ │
│ ├───────────────────────────────┤ │                 │ │
│ │ {Name_4}│ {View_4}            │ │ {BOM 표}        │ │
│ ├───────────────────────────────┤ │ 5행 슬롯        │ │
│ │ {Name_5}│ {View_5}            │ │                 │ │
│ └───────────────────────────────┘ └─────────────────┘ │
│ ↑ 좌측 좌측 영역 (전체 너비 약 75%)  ↑ 우측 (25%)      │
│   - BOM이름:View = 1:3 (좌 약 19% / 우 약 56%)         │
└─────────────────────────────────────────────────────────┘
```

### 3.2 엑셀 슬롯 명명 (SDK 정식 태그)

**중요 (codex 1차 정정)**: SDK는 **`{Input_N}` 태그**를 `Dictionary<int,string> data`의 `N`과 매핑. **`#1`, `{1}` 같은 표기는 매핑 안 됨**. `GetViewAreasFromExcel`은 별도로 `{View_N}` 태그 파싱. 같은 xlsx에 둘 다 사용 가능.

**도면정보 슬롯**:
| SDK 태그 | data 키 | 용도 |
|---|---|---|
| `{Input_1}` | 1 | 프로젝트명 |
| `{Input_2}` | 2 | 선박번호 |
| `{Input_3}` | 3 | 도면 종류 ("가공도") |
| `{Input_4}` | 4 | 페이지 번호 ("1/3" 형식) |

**행별 부재 이름 슬롯** (5행):
| SDK 태그 | data 키 | 용도 |
|---|---|---|
| `{Input_5}` | 5 | Row1 BOM 이름 |
| `{Input_6}` | 6 | Row2 BOM 이름 |
| `{Input_7}` | 7 | Row3 BOM 이름 |
| `{Input_8}` | 8 | Row4 BOM 이름 |
| `{Input_9}` | 9 | Row5 BOM 이름 |

**행별 BOM 메타 슬롯** (5행 × 4 컬럼 = 20):
| SDK 태그 범위 | data 키 | 용도 |
|---|---|---|
| `{Input_10}`~`{Input_14}` | 10~14 | Row1~5 ITEM |
| `{Input_15}`~`{Input_19}` | 15~19 | Row1~5 MATERIAL |
| `{Input_20}`~`{Input_24}` | 20~24 | Row1~5 SIZE |
| `{Input_25}`~`{Input_29}` | 25~29 | Row1~5 Q'TY |

**모델 뷰 영역** (`{View_N}` 태그, `GetViewAreasFromExcel`):
- `{View_1}` ~ `{View_5}` = 행별 모델 영역
- 영역 비율: 행 너비의 약 75% (BOM이름 슬롯이 25%)
- 영역 높이: 페이지 - 도면정보·헤더·푸터 영역 분할 / 5

### 3.3 엑셀 파일 작성 가이드 (사용자용)

1. 새 엑셀 파일 `사용자템플릿_엑셀_가공도.xlsx` 생성 (솔루션 루트에 배치)
2. A4 가로 페이지 (297×210mm)
3. 5행 × 2열 그리드 (좌 BOM이름 + 우 View, 1:3 비율)
4. 우측: 도면정보 + BOM 표 영역 (별도)
5. **각 슬롯 셀에 정확히 `{Input_N}` 텍스트 입력** (예: `{Input_1}`, `{Input_5}` 등). **`{1}` 또는 `#1` 표기는 작동 안 함**
6. **각 모델 영역 셀에 정확히 `{View_N}` 텍스트 입력** (예: `{View_1}`)
7. 외곽 테두리·로고는 직접 디자인 (제작도 템플릿 참고)

### 3.4 `GetViewAreasFromExcel` 캐시 정책 (codex 권고)

- 5개 영역은 페이지 데이터와 무관한 템플릿 기하 정보

### 4.1.1 `_v2` 진입부 강제 초기화 8단계 (codex 권고)

수동·자동 사전 상태 차이가 결과 차이를 만들지 않도록 진입부 명시:

```csharp
private int GenerateMfgDrawing2DAll_v2(List<DrawingSheetData> mfgSheets, ...)
{
    // ── 강제 초기화 8단계 (수동·자동 동일 결과 보장) ──
    vizcore3d.Review.Note.Clear();                          // 1
    vizcore3d.Review.Measure.Clear();                       // 2
    vizcore3d.ShapeDrawing.Clear();                         // 3
    Clear2DView();                                           // 4 (DeleteAllObject + RemoveCanvas 포함)
    if (vizcore3d.View.XRay.Enable)                          // 5
        vizcore3d.View.XRay.Enable = false;
    vizcore3d.Object3D.Show(VIZCore3D.NET.Data.Object3DKind.ALL, true);  // 6 (전체 보기 시작점)
    vizcore3d.Object3D.Select(VIZCore3D.NET.Data.Object3dSelectionModes.DESELECT_ALL);  // 7
    vizcore3d.View.SetRenderMode(VIZCore3D.NET.Data.RenderModes.DASH_LINE);  // 8 (PDF 은선용)

    // 페이지 분할 (v2.1: TemplateViewArea 캐시는 첫 페이지 import 후 1회 추출)
    var pages = SplitMfgIntoPages(mfgSheets);
    List<VIZCore3D.NET.Data.TemplateViewArea> viewAreasCache = null;  // 첫 페이지 import 후 채움

    foreach (var page in pages)
    {
        // ── 페이지 진입부 (잔재 방지) ──
        Clear2DView();
        vizcore3d.Drawing2D.View.SetCanvasSize(297, 210);
        vizcore3d.Drawing2D.View.SetSelectCanvas(1);
        
        var data = BuildMfgPageData(page, pages.Count, struName);
        vizcore3d.Drawing2D.Template.ImportExcelWithData(xlsxPath, data);

        // v2.1: GetViewAreasFromExcel은 ImportExcelWithData 후 호출 (SDK 패턴)
        if (viewAreasCache == null)
            viewAreasCache = vizcore3d.Drawing2D.Template.GetViewAreasFromExcel(xlsxPath);
        
        for (int i = 0; i < page.Rows.Count; i++)
        {
            var sheet = page.Rows[i];
            var bom = bomList.FirstOrDefault(b => b.Index == sheet.MemberIndices[0]);
            if (bom == null) continue;
            // viewAreasCache[i]는 TemplateViewArea — 속성: Index/X/Y/Width/Height
            // Center는 호출자가 계산: cx = X + Width/2, cy = Y + Height/2
            RenderMfgRowToViewArea(i + 1, bom, viewAreasCache[i]);
        }

        // ── 페이지 PDF export (v2.1: _v2가 PDF 소유, 호출부 중복 export 금지) ──
        string pdfPath = Path.Combine(saveDir, $"{struName}_가공도_p{page.PageIdx}of{pages.Count}_{ts}.pdf");
        vizcore3d.Drawing2D.Object2D.Export2PDFBy2DView(pdfPath);
    }
    return pages.Count;  // 생성된 페이지 수 반환 (호출부: pdfCount += pages)
}
```

### 4.1.2 PDF export 호출부 감사 (v2.1, codex 2차 #5)
`_v2`가 PDF export를 소유하므로 다음 호출부에서 **기존 Export2PDFBy2DView 호출 제거**:
- `Form1.Stru.cs` `ProcessSingleStruFull` 가공도 묶음 처리 (현재 L711 부근)
- `Form1.MfgDrawing.cs` `btnMfgDrawingSheet_Click` (현재 본체)
- **`Form1.DrawingSheets.cs:1181`** 부근 가공도 export 흐름 (codex 2차 발견 — 추가 감사)

**codex 정정 (🔴 위험)**: `MoveObject(dx, dy)`는 **delta 이동**이라 두 뷰를 각각 영역 fit 후 밀면 위치 안 맞음. 안전 패턴:

**v2.1 정정 (codex 2차 #2·#3)**:
- 영역 타입은 SDK 정식 **`TemplateViewArea`** (속성: `Index/X/Y/Width/Height`)

// EA 두 뷰 배치 — codex 권고 (v2.1):
//   1. TemplateViewArea를 좌/우 두 sub-region으로 분할 (X, Y, Width/2, Height)
//   2. 두 뷰의 fit ratio 계산 후 더 작은 ratio 채택 → 같은 absolute scale로 통일
//   3. MoveObjectTo (delta 아님, 절대 좌표)로 각 sub-region 중심에 배치

private void RenderMfgRowToViewArea(int viewIdx, BOMData bom, VIZCore3D.NET.Data.TemplateViewArea area)
{
    if (IsAngleFromSpref(bom.Index))
    {
        // EA 부재 — 두 뷰
        // 좌/우 sub-region (TemplateViewArea 직접 인스턴스화 X — 좌표만 계산)
        float leftX  = area.X,                rightX = area.X + area.Width / 2f;
        float subW   = area.Width / 2f,       subH   = area.Height;
        float leftCx = leftX  + subW / 2f,    rightCx = rightX + subW / 2f;
        float cy     = area.Y + subH / 2f;
        
        var pose1 = BuildMfgSceneCore(bom.Index);  // 일반 카메라
        int objId1 = vizcore3d.Drawing2D.Object2D.Create2DViewObjectWithModelHiddenLineAtCanvasOrigin(...);
        
        // 위에서 다시 카메라 (Z 방향)
        vizcore3d.View.MoveCamera(VIZCore3D.NET.Data.CameraDirection.Z_PLUS);
        // ... 꺾인 방향 결정 로직 (옛 EA 코드 git history 참조: refactor/dead-code 분기 이전)
        int objId2 = vizcore3d.Drawing2D.Object2D.Create2DViewObjectWithModelHiddenLineAtCanvasOrigin(...);
        
        // v2.1: fit ratio 계산 후 같은 absolute scale로 통일
        //   GetObjectSize → 객체 현재 크기 / GetObjectScale → 객체 현재 절대 scale
        //   fit ratio = min(subW/objW, subH/objH)
        //   target absolute scale = GetObjectScale * fitRatio
        float r1 = ComputeFitRatio(objId1, subW, subH);  // helper: 비율만 반환
        float r2 = ComputeFitRatio(objId2, subW, subH);
        float commonRatio = Math.Min(r1, r2);
        
        // RescaleObject는 절대 스케일 → "현재 scale × commonRatio" 전달
        float curScale1 = vizcore3d.Drawing2D.Object2D.GetObjectScale(objId1);
        float curScale2 = vizcore3d.Drawing2D.Object2D.GetObjectScale(objId2);
        vizcore3d.Drawing2D.Object2D.RescaleObject(objId1, curScale1 * commonRatio);
        vizcore3d.Drawing2D.Object2D.RescaleObject(objId2, curScale2 * commonRatio);
        
        // 절대 좌표로 배치
        vizcore3d.Drawing2D.Object2D.MoveObjectTo(objId1, leftCx, cy);
        vizcore3d.Drawing2D.Object2D.MoveObjectTo(objId2, rightCx, cy);
    }
    else
    {
        // 일반 부재 — 단일 뷰 (C-Mfg-4)
        // 동일 패턴: GetObjectScale × fit ratio → RescaleObject
        ...
    }
}

// 신규 helper (C-Mfg-4):
private float ComputeFitRatio(int objId, float targetW, float targetH)
{
    float objW = 0f, objH = 0f;
    vizcore3d.Drawing2D.Object2D.GetObjectSize(objId, ref objW, ref objH);
    if (objW <= 0 || objH <= 0) return 1.0f;
    return Math.Min(targetW / objW, targetH / objH);
}
